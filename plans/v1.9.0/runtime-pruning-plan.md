# Runtime & Overlay Pruning — Design Plan

**Version:** v1.9.0  
**Status:** Draft  
**Related:** [`plans/v1.9.0/overlays-to-go-plan.md`](overlays-to-go-plan.md) (prerequisite: every phase), [`plans/v1.9.0/stdlib-in-go-plan.md`](stdlib-in-go-plan.md), [`plans/v1.9.0/compiler-shrinking-plan.md`](compiler-shrinking-plan.md), [`plans/v1.9.0/follow-ups-2026-11-07-plan.md`](follow-ups-2026-11-07-plan.md) (`F73` scheduled here)  
**Release note:** `encoding/json` can now be imported under an alias (`import myjson "encoding/json"`), `json.RawMessage` has its `MarshalJSON` and `UnmarshalJSON` methods, and single-file builds (`gofront main.go`) work with `encoding/json` and `errors.As`. Programs that use `encoding/json` produce smaller JavaScript, and WebAssembly packages that import `time` ship less JavaScript glue.  

---

## Goal

Finish the v1.9.0 "Stdlib in Go" compiler cleanup after [`overlays-to-go-plan.md`](overlays-to-go-plan.md) lands (all seven phases): retire the last hybrid typechecker overlay (`encoding/json`) and the `pkg.overlay` merging in [`src/link/stdlib.js`](../../src/link/stdlib.js), drop the stale `JSON_NAMES` / `addExtraRoots` roots in [`src/lower/reachability.js`](../../src/lower/reachability.js), unify import qualification and closed-world type discovery across the `src/lower/` generators (`json-codecs.js`, `errors-as.js`, and `fmt-formatters.js` from overlays-to-go Task 4.3) and make `compileSingleFile` (`src/compiler.js`) delegate to `compileFiles`, dissolve the emptied `src/typechecker/stdlib/{core,extended}.js`, `src/backend/wasm/stdlib/{core,io}.js` and single-method `src/backend/js/stdlib/{shared,simd}.js`, and delete dead WebAssembly runtime emission code (`__errors_is` / `__errors_unwrap`, `emitMapClone`, `_emitLazyErrorGlobal`, `getIoErrGlobalIndex`, `UTF8_CONSTS`, `ERROR_PRODUCING_PKGS`, `hasIo`, `STDLIB_IMPORTS` / `WASM_STDLIB_JS`) plus the duplicated map lookup / keys / values emitters.

User-visible fixes: aliased `encoding/json` imports, local variables named `json`, `json.RawMessage` methods, `json.Marshal`/`Valid` used as values (today a runtime `ReferenceError`), single-file builds using `json`/`errors.As`, cross-file aliased imports in generated `gofront_gen.go`, smaller JS for `encoding/json` users, and no dead `bytes_trim` glue in WASM facades. The WASM dead-helper pruning is compiler-source cleanup: linked `app.wasm` output is already pruned by `pruneUnusedFuncs` (see Verified Gaps), so only `exportAll` builds (the in-memory `compileWasm`) change.

**Done means:**
- `"encoding/json"` is removed from `STDLIB_PACKAGES` ([`src/typechecker/types.js`](../../src/typechecker/types.js)), the `json` overlay block is gone, every `overlay` parameter/branch is removed from [`src/link/stdlib.js`](../../src/link/stdlib.js), `JSON_NAMES`/`addExtraRoots` are removed from [`src/lower/reachability.js`](../../src/lower/reachability.js), and `import myjson "encoding/json"`, `json.RawMessage.MarshalJSON`/`UnmarshalJSON`, a local variable named `json`, and `f := json.Valid` pass JS/WASM parity (`assertAllTargetsOutput`) in `test/unit/builtins/json.test.js`, while `f := json.Marshal` fails with `json.Marshal cannot be used as a value` (`assertErrorContains`).
- `src/lower/gen-types.js` is the single home of `importsFor`, canonical import qualification, `SHARED_REPR`/`hasSharedRepr`/`isEmptyIface`/`spellable` and `collectProgramTypes`; `compileSingleFile` delegates to `compileFiles`; cross-file aliased imports (`import t "time"`, `import sc "strconv"`) with `json.Marshal` and `errors.As` pass in `test/unit/builtins/json.test.js` and `test/unit/compiler/stdlib-go.test.js`; a single-file build using `json.Marshal`, `errors.As` and `fmt.Sprintf` runs in `test/unit/compiler/packages.test.js`.
- `src/typechecker/stdlib/core.js`, `src/typechecker/stdlib/extended.js`, `src/backend/wasm/stdlib/core.js`, `src/backend/wasm/stdlib/io.js`, `src/backend/js/stdlib/shared.js` and `src/backend/js/stdlib/simd.js` are deleted; `STDLIB_IMPORTS`, `STDLIB_ENV_PKGS`, `usesStdlibEnv`, `getStdlibImportIndex` and `WASM_STDLIB_JS` are gone, `time_now_ms`/`time_timezone_offset` are registered by the `time_now`/`time_zone_offset` intrinsics' `prepare`, and the facade of a wasm package importing `time` contains no `bytes_trim` (`test/unit/wasm/stdlib.test.js`).
- `emitMapClone`, `__errors_is` and `__errors_unwrap` are deleted, compiler-synthesised helpers (`_isMapHelper`, `_isInterfaceDispatcher`, `_isSharedHelper`, `_isRuntimePanic`, `_isIndexPanic`) are no longer exported under `options.exportAll`, so the test helper `compileWasm` WAT for a map-lookup-only module contains no `$__map_clone_`/`$__map_delete_`/`$__map_clear_`/`$__map_keys_`/`$__map_values_` (`test/unit/wasm/maps.test.js`) and an `errors.New` module no `$__errors_is`/`$__errors_unwrap` (`test/unit/stdlib/errors.test.js`).
- `npm run check && npm test && npm run test:e2e` pass with zero regressions, and `find src -name '*.js' -exec cat {} + | wc -l` drops by ≥ 800 lines against the value recorded at the start of Phase 1 (post-`overlays-to-go` tree).

## Approach

### 1. Architecture & Design Decisions

- **`encoding/json` in Go source, no hybrid overlays (Phase 1):**
  - Add `stdlib/encoding/json/json.go` (`//gofront:target both`): `type RawMessage []byte` with `func (m RawMessage) MarshalJSON() ([]byte, error)` (`nil` → `null`) and `func (m *RawMessage) UnmarshalJSON(data []byte) error` (nil receiver → `errors.New("json.RawMessage: UnmarshalJSON on nil pointer")`, copies with `*m = append((*m)[0:0], data...)`); `func Valid(data []byte) bool { return jsonrt.Valid(data) }`; and `Marshal`, `MarshalIndent`, `Unmarshal` stubs that `panic("json.<Name>: call sites are rewritten by the compiler")`, whose call sites keep being specialized by [`generateJsonCodecs`](../../src/lower/json-codecs.js) via `_genEntry` (the `errors.As` pattern in [`stdlib/errors/errors.go`](../../stdlib/errors/errors.go)).
  - In the same commit delete the `json` namespace / `RAW_MESSAGE_T` block from [`src/typechecker/stdlib/extended.js`](../../src/typechecker/stdlib/extended.js) and `"encoding/json"` from `STDLIB_PACKAGES`: `probeStdlibPackage` rejects Go declarations that collide with overlay members, so the Go file and the overlay cannot coexist. Extend `isRaw` in `json-codecs.js` to the mangled `RawMessage$$` name (as `isNumber` does) and keep `isRaw` ahead of `marshalerOf`/`unmarshalerOf` so the codecs keep the validate-and-compact fast path.
  - In `json-codecs.js` `findSites`, require `node.func.expr._type?.kind === "namespace"` in `isJsonCall`, drop `Valid` from the rewritten members (`SITE_FUNCS`, `entryValid`, the `selectCodecEntry` fallback), and report `json.<Name> cannot be used as a value` for a non-call `Marshal`/`MarshalIndent`/`Unmarshal` selector (same diagnostic path as `errors-as.js:105`).
  - Delete `EncodeBytes` / `DecodeBytes`; inline `OptEscapeHTML` (`EscapeHTML: true`) and drop `OptUseNumber` / `OptDisallowUnknownFields` (zero values) in `stdlib/internal/jsonrt/`; delete `JSON_NAMES` and `addExtraRoots` (overlays-to-go Task 7.4 already removed its testing branch).
  - Fold the `BROWSER_GLOBALS` loop (`core.js`) and the `BUILTINS` registration (`extended.js`) into [`src/typechecker/stdlib/index.js`](../../src/typechecker/stdlib/index.js) and delete both files.
  - Delete every `overlay` parameter/branch from `src/link/stdlib.js` (`mangleTypeRef`, `mangleIdentRef`, `checkStdlibPrograms`, `probeStdlibPackage`, `installLazyBodies`, `stdlibNamespace`, `buildStdlibPackage`, `bindStdlibImport`), the overlay wording in `src/resolver.js`, and `GO_OVERLAID_PACKAGES` / `GO_MEMBER_PACKAGES` in `test/unit/helpers.js`.

- **Shared import qualification, type discovery & `compileSingleFile` (Phase 2):** depends on `src/lower/fmt-formatters.js` from overlays-to-go Task 4.3.
  - In [`src/lower/gen-types.js`](../../src/lower/gen-types.js), `TypeSpeller` builds `alias|defaultName → modPath` across `programs` and spells every cross-package type with the canonical package name (`sc.NumError` / `NumError$$strconv` → `strconv.NumError`). If a package-level declaration in `programs` uses that name, `importsFor` emits `import _gf_<name> "<path>"` and `TypeSpeller` spells `_gf_<name>.T`. `checkGeneratedGo` accepts `{ path, alias }` import entries.
  - Move `importsFor`, `SHARED_REPR`, `hasSharedRepr`, `isEmptyIface`, `spellable` and `collectProgramTypes(programs, checker)` into `gen-types.js`, replacing the copies in `json-codecs.js` (`programTypes`, inline import map), `errors-as.js` (`importsFor`) and whatever equivalents `fmt-formatters.js` lands with (its operand type enumeration and representation filter).
  - `compileSingleFile` keeps `dumpTokens` / `dumpAst` and then returns `compileFiles([resolve(inputPath)], { ...options, outputDir: options.outputDir ?? (outputFile ? dirname(resolve(outputFile)) : resolve(".")) })`, preserving today's output-directory default.

- **WASM dead runtime & `wasm/stdlib/` dissolution (Phase 3):** depends on overlays-to-go Tasks 6.1, 6.2 and 7.4.
  - Delete `__errors_is` / `__errors_unwrap` (`index.js`, `core.js` `errors_is` arm), `_emitLazyErrorGlobal`, `getIoErrGlobalIndex` / `ioErrGlobals`, `UTF8_CONSTS` / `_isUtf8Const` / `emitUtf8Const` (and the `emit-exprs.js:614` branch), `ERROR_PRODUCING_PKGS` (`hasErrorType = hasErrorUsage(programs)`), and `hasIo`.
  - `time_now` / `time_zone_offset` get `prepare: (mod) => mod.getOrAddFuncImport("env", "time_now_ms", [], ["f64"])` (resp. `time_timezone_offset`, `["f64"]`, `["i32"]`) and `emit` uses the same call; the two JS functions move into the `WASM_IMPORTS_JS` env table next to `os_*`. Then delete `STDLIB_IMPORTS`, `STDLIB_ENV_PKGS`, `getStdlibImportIndex`, `usesStdlibEnv`, the `stdlibEnv` flag, `WASM_STDLIB_JS` (including `HELPER_ERROR`, which only the removed fmt engine read) and `importsAnyOf`.
  - Move `emitRuntimeHelper`, `_emitAnyEq` and `emitSliceClear` from `src/backend/wasm/stdlib/core.js` into [`src/backend/wasm/emit-builtins.js`](../../src/backend/wasm/emit-builtins.js); delete `core.js` and `io.js` and drop them from `stdlibEmitters` (`src/backend/wasm/stdlib/index.js`).
  - Inline `src/backend/js/stdlib/shared.js` (17 lines) and `simd.js` (34 lines) into `src/backend/js/stdlib/index.js`.

- **WASM map emitter pruning (Phase 4):**
  - Delete `emitMapClone`, its `funcDecls` entry (`index.js:597-607`), the `clone` dispatch arm and `cloneFuncName` (`module-emitter.js:780`).
  - Skip synthesised helpers (`_isMapHelper`, `_isInterfaceDispatcher`, `_isSharedHelper`, `_isRuntimePanic`, `_isIndexPanic`) in the `options.exportAll` export rule (`index.js:906-916`) so `pruneUnusedFuncs` strips them in `exportAll` builds as it already does in linked builds; boundary helpers stay exported through `boundary.js`'s own exports.
  - Merge `emitMapKeys` / `emitMapValues` into `emitMapProject(mapInfo, isValues)` and `emitMapGet` / `emitMapGetOk` into `emitMapLookup(mapInfo, withOk)`.

### 2. Invariants & Safety Bounds

- **Zero hybrid overlays:** after Phase 1, `STDLIB_PACKAGES` is `{gofront/shared, gofront/simd}` (no directory under `stdlib/`), and every package under `stdlib/` is Go source (optionally with `//gofront:native` / `//gofront:intrinsic` and `src/lower/` call-site specialisation).
- **Linked output unchanged by WASM pruning:** Phases 3–4 must not change `app.wasm` produced by `compileDir` for existing fixtures except for removed dead imports; `test/unit/wasm/golden.test.js` and `test/unit/compiler/optimize-build.test.js` stay green.
- **WASM export hygiene:** under `exportAll` only user functions (and boundary/`__push_panic` exports) are exported; synthesised helpers never are.
- **Sentrux layer & complexity gate:** zero circular dependencies; `npm run check` green at every commit (moving ~380 lines into `emit-builtins.js` must stay under the complexity gate; split into a sibling `emit-runtime.js` if it does not).

### 3. Edge Cases & Error Handling

- **`json` functions as values:** `f := json.Valid` works (plain Go). `f := json.Marshal` / `MarshalIndent` / `Unmarshal` → compile error `json.Marshal cannot be used as a value` (resp. member name), matching `errors.As`; the stub bodies never run.
- **`json.RawMessage` nil receiver / aliasing:** `(*RawMessage)(nil).UnmarshalJSON(b)` returns `json.RawMessage: UnmarshalJSON on nil pointer`; `UnmarshalJSON` copies `data`, so later writes to the input buffer do not change the message; `RawMessage(nil).MarshalJSON()` returns `null`.
- **Shadowed package names in `gofront_gen.go`:** a package-level `var time = 123` in one file plus `import t "time"` in another (valid Go: the file-scoped import does not collide) makes `importsFor` emit `import _gf_time "time"` and `TypeSpeller` spell `_gf_time.Time`. (An unaliased `import "time"` alongside a package-level `time` is invalid Go and stays rejected.)
- **`compileSingleFile` defaults:** delegation keeps `outputDir = resolve(".")` when neither `outputDir` nor `outputFile` is given, and `dumpTokens` / `dumpAst` still return before any type checking.
- **`hasErrorType` without `ERROR_PRODUCING_PKGS`:** runtime panics (index out of range, nil map write) in a wasm package that imports `strings`/`time` but never names `error` still report their message (raw string path of `emitRuntimePanicThrow`); `recover()` as `error` needs the program to name `error`, which `hasErrorUsage` detects.
