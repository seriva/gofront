# Follow-ups

Bugs noticed outside the task at hand, each with a repro so it can be re-checked later. Written by `/bs-loop` reviewers and by any agent session. Open items only: `/bs-plan follow-ups` re-probes them and moves each into a plan (as a fix task or a deferred row), deleting it here.

A defect with the same root as the task being fixed is part of that task and never lands here (`/bs-loop` **Follow-ups**).

- **JS backend:** Shifting an `int` by 32 or more in a `js` package uses JavaScript's 32-bit `<<`, so the result is wrong although `int` holds integers up to 2⁵³ there. Repro: `func G(s uint) { one := 1; fmt.Println(one << s) }; G(40)` → got `256`, want `1099511627776`. (feat/checker-go-rules-phase-16)
- **WASM backend:** A generic defined type over a generic struct that embeds another generic struct fails to compile on `wasm`. Repro: `type Inner[A any] struct{ Y A }; type S[A any] struct{ Inner[A]; X A }; type W[B any] S[B]; w := W[int]{Inner: Inner[int]{Y: 11}, X: 22}; fmt.Println(w.Y, w.X, w.Inner.Y)` → got `internal compiler error: Unknown field 'Inner' on struct 'W$int'` on `wasm`, want `11 22 11`. (PR #249)
- **Checker:** Methods declared on a generic type whose underlying type is not a struct or interface are lost when it is instantiated. Repro: `type W[T any] []T; func (w W[T]) Len() int { return len(w) }; fmt.Println(W[int]{1, 2, 3}.Len())` → got `W[int] has no field or method 'Len'` on all targets, want `3`. (PR #249)
- **Backends:** Converting a struct value to its own type returns the same object instead of a copy, so writes through the result change the source. Repro: `type T struct{ X int }; src := T{X: 1}; dst := T(src); dst.X = 2; fmt.Println(src.X, dst.X)` → got `2 2` on `js` (and on `wasm` for `type T[A any] struct{ X int }` with `T[int]`), want `1 2`. (PR #249)
- **JS backend:** `clear`, `len` and `copy` on a type-parameter operand pick their JavaScript form from the operand's static type, so a type parameter is lowered as a slice: `clear` on a map (also with `M ~map[K]V`) throws, `clear` on `S ~[]int` fills with a wrong zero, `len` of a `~*[3]int` term reads `.length` of the pointer, and `copy` from a `~[]byte | ~string` source copies zeros. Repro: `func C[M ~map[string]int](m M) { clear(m) }; C(map[string]int{"a": 1})` → got `m?.fill is not a function` (js/both), want no output and `len(m) == 0` (wasm correct); `func L[T ~[]int | ~*[3]int](v T) int { return len(v) }; a := [3]int{}; L(&a)` → got `1`, want `3`; `cap(v)` with `T ~[3]int | ~*[3]int` on `F(&a)` → got `-9223372036854775808`, want `3`; `append([]byte{}, v...)` with `T ~string | ~[]byte` on `"hi"` → got `\u0000\u0000`, want `hi`. (PR #250)
- **Checker:** `len(v)` of a type-parameter value is treated as a constant, so `const n = len(v)` compiles. Repro: `func F[T ~[3]int](v T) int { const n = len(v); return n }` → got accepted on `js`/`wasm`, want `len(v) (value of type int) is not constant`. (PR #250)
- **JS backend:** A local or parameter of type-parameter type named `true` (or `yield`) skips JS value renaming, so the program reads `-9223372036854775808`. Repro: `func f[T any](x T) T { true := x; return true }; func main() { fmt.Println(f(42)) }` → got `-9223372036854775808` on js, want `42`. (PR #253)
- **Checker:** A local variable that shadows a non-`nil` type name is not rejected as a type in a type-switch case. Repro: `int := 1; _ = int; switch any(1).(type) { case int: }` → got accepted, want `int (local variable) is not a type`. (PR #253)
- **JS backend:** `string(t)` with `T ~string | ~[]byte` joins the bytes with commas for a `[]byte` argument. Repro: `func str[T ~string | ~[]byte](t T) string { return string(t) }; fmt.Println(str([]byte("cd")))` → got `99,100` on js, want `cd`. (feat/checker-go-rules-phase-22)
- **Checker:** `[2]int` assigns to `[2]any` and `*int` to `*any`, since an array element or pointer base is checked for assignability instead of identity. Repro: `var b [2]int; var t [2]any = b` → got accepted, want `cannot use b (variable of type [2]int) as [2]any value`. (feat/checker-go-rules-phase-22)
- **JS backend:** `T(1.5)` with `T ~complex128` and `T(65)` with `T ~string` miscompile on js. Repro: `func f[T ~complex128]() T { return T(1.5) }; func main() { fmt.Println(f[complex128]()) }` → got `(NaN+NaNi)` on js, want `(1.5+0i)`; `func f[T ~string]() T { return T(65) }` → got `65`, want `A`. (PR #254)
- **Checker:** Method expressions on an interface or type parameter (`N.M(x)`, `T.M(t)`) are rejected with `Too many arguments`. Repro: `type N interface{ M() int }; type A struct{}; func (A) M() int { return 9 }; func f[T N](t T) int { return T.M(t) }` → got `Too many arguments: expected 0, got 1`, want `9`. (PR #255, PR #259)
- **Checker:** A selector on a multi-level pointer is accepted. Repro: `func f[T ~struct{ X int }](p **T) int { return p.X }` → got accepted on js/both/wasm, want `p.X undefined (type **T has no field or method X)`. (PR #255)
- **Compiler:** A dot-imported package type is mangled when the importer declares a local type of the same name. Repro: package `dot` declares `type Reader struct{ N int }`, `main` dot-imports it and declares `func f() { type Reader struct{ S string } }` → got `Unknown type 'Reader'` in `main`, want it to resolve to `dot.Reader`. (PR #258)
- **Checker:** A local struct that embeds a package-level struct does not get its promoted methods. Repro: `type Base struct{ N int }; func (b Base) Get() int { return b.N }; func main() { type Sub struct{ Base }; s := Sub{Base{N: 12}}; fmt.Println(s.Get()) }` → got `No field 'Get' on Sub`, want `12`. (PR #258)
- **WASM backend:** A local type declared inside a generic function fails on wasm. Repro: `func g[T any](v T) { type Q struct{ X T }; q := Q{X: v}; fmt.Println(q.X) }; func main() { g(5); g("hi") }` → got invalid WebAssembly on wasm, want `5` then `hi`. (PR #258)
- **WASM backend:** A self-referential local pointer type overflows the stack on wasm. Repro: `func main() { type Q *Q; var q Q; fmt.Println(q == nil) }` → got `Maximum call stack size exceeded` on wasm, want `true`. (PR #258)
- **Checker:** Converting with an instantiated generic alias is rejected. Repro: `type Box[T any] struct{ V T }; type Alias[T any] = Box[T]; b := Box[int]{V: 5}; _ = Alias[int](b)` → got `Alias (type) is not an expression`, want it to compile. (PR #259)
- **Checker:** `complex(a, b)` accepts non-float operands. Repro: `a, b := 1, 2; fmt.Println(complex(a, b))` → got `(1+2i)` on js and an invalid-module error on wasm, want `invalid argument: arguments have type int, expected floating-point`. (PR #261)
- **Checker:** `defer min(f2())` fails on wasm and compiles silently on js. Repro: `defer min(f2())` → got an invalid-module error on wasm, want `defer discards result of min`. (PR #261)
- **Checker:** `const c = min(a, b)` with non-constant operands is accepted. Repro: `a, b := 1, 2; const c = min(a, b)` → got accepted, want `min(a, b) (value of type int) is not constant`. (PR #261)
- **Checker:** A variable that is only assigned is accepted as used, including a type-switch binding. Repro: `x := 1; x = 2` in `main` → got accepted, want `declared and not used: x`. (PR #262)
- **Checker:** The init statement of a type switch is not in scope inside its clauses. Repro: `switch y := 1; x := v.(type) { case int: _ = y; _ = x }` → got `Undefined: 'y'`, want accepted. (PR #262)
- **Checker:** A type parameter compared with a value of a different type is accepted. Repro: `func f[T comparable](a T, b error) bool { return a == b }` → got accepted, want `invalid operation: a == b (mismatched types T and error)`. (PR #264)
- **WASM backend:** Comparing two `[2]any` arrays crashes the compiler. Repro: `func f(a, b [2]any) bool { return a == b }` in a `wasm` package → got internal compiler error `__any_eq was not declared`, want a valid module. (PR #264)
- **Parser:** Channel types and a pointer as the first type-parameter constraint do not parse. Repro: `func f(s chan int) {}` and `func g[T *int](x T) {}` → got `Parse error ... expected ')' (got chan)` and `expected '('`, want accepted by Go (`chan` is out of scope by design; the constraint form should parse). (PR #264)
- **Diagnostics:** A rune literal prints as its value and `any` operands report `operator + not defined` where Go reports a mismatch. Repro: `var s string; _ = s + 'a'` and `var a any; _ = a + 1` → got `x + 97 (mismatched types ...)` and `operator + not defined on a (variable of type any)`, want `s + 'a' (mismatched types string and untyped rune)` and `mismatched types any and untyped int`. (PR #264)
- **Diagnostics:** A nested non-constant shift in a float or complex context names the outer shift as the shifted operand. Repro: `s := uint(1); var f float64 = (1 << s) << 1; _ = f` → got `shifted operand 1 << s (type float64) must be integer`, want `shifted operand 1 (type float64) must be integer`. (PR #265)
- **Checker:** Typed complex constants are not folded in constant expressions. Repro: `const c complex128 = 3 + 4i; var a [int(real(c))]int` → got `invalid array length expression (value of type int): must be constant`, want accepted. (PR #266)
- **Checker:** An undefined receiver type reports a second, spurious error. Repro: `func (u U) M() {}` → got `Unknown type 'U'` plus `cannot define new methods on non-local type U`, want a single `undefined: U`. (PR #268)
- **Parser:** A parenthesized receiver type does not parse. Repro: `type P struct{}; func (p (P)) M() {}` → got `Parse error ... Expected type, got '('`, want accepted. (PR #268)
- **Checker:** A method declared on an alias of a local struct is not found on the struct. Repro: `type P struct{ n int }; type A = P; func (a A) Get() int { return a.n }; func main() { var p P; fmt.Println(p.Get()) }` → got `p.Get is not a function` at runtime on js, want `0`. (PR #268)
- **JS backend:** A `switch` on a type-parameter tag instantiated with a struct or array compares by reference. Repro: `type P struct{ X int }; func f[T comparable](x, y T) bool { switch x { case y: return true }; return false }; func main() { fmt.Println(f(P{1}, P{1})) }` → got `false` on js, want `true`. (PR #269)
- **Compiler:** Complex compound assignment and `++`/`--` evaluate an index expression three times. Repro: `calls := 0; idx := func() int { calls++; return 0 }; s := []complex128{1i}; s[idx()]++; fmt.Println(calls)` → got `3` on js, both and wasm, want `1`. (PR #270)
- **JS backend:** A promoted selector through an embedded alias of an anonymous struct reads the zero value. Repro: `type A = struct{ N int }; func main() { v := struct{ A }{A{5}}; fmt.Println(v.N, v.A.N) }` → got `0 5` on js and both, want `5 5`. (PR #278, wasm-struct-types Phase 1)
- **JS backend:** A two-level embedded promotion on an anonymous struct reads the wrong field. Repro: `type A struct{ X int }; type B struct{ A }; func main() { v := struct{ B; Y int }{B{A{7}}, 8}; fmt.Println(v.X, v.A.X, v.B.X, v.Y) }` → got `7 0 7 8` on js and both, want `7 7 7 8`. (PR #278, wasm-struct-types Phase 1)
- **JS backend:** `map[any]int` keys `struct{ P }` and `struct{ P P }` collapse into one entry. Repro: `type P struct{ N int }; func main() { m := map[any]int{}; k1 := struct{ P }{P{1}}; k2 := struct{ P P }{P{1}}; m[k1] = 10; m[k2] = 20; fmt.Println(m[k1], m[k2], len(m)) }` → got `20 20 1` on js and both, want `10 20 2`. (PR #278, wasm-struct-types Phase 1)
- **Compiler:** `%T` of a generic instance whose type argument is an anonymous struct lists grouped fields as one on js and both. Repro: `type Box[T any] struct{ v T }; func main() { fmt.Printf("%T\n", Box[struct{ X, Y int }]{}) }` → got `main.Box[struct { X, Y int }]` on js and both, want `main.Box[struct { X int; Y int }]`. (wasm-struct-types Phase 2)
- **Compiler:** `%T` of a generic instance whose type argument is an anonymous interface prints an empty line on js, both and wasm. Repro: `type Box[T any] struct{ v T }; func main() { fmt.Printf("%T\n", Box[interface{ M() int }]{}) }` → got an empty line, want `main.Box[interface { M() int }]`. (wasm-struct-types Phase 2)
- **WASM backend:** A struct with an anonymous-interface field fails to build when no type implements the interface. Repro: `type Box struct{ v interface{ M() int } }; func main() { fmt.Printf("%T\n", Box{}) }` → got `internal compiler error: no wasm dispatcher for interface method anon_iface_M__int.M` on wasm, want `main.Box`. (wasm-struct-types Phase 2)
- **WASM backend:** Calling a method through an anonymous-interface field of an anonymous struct fails to build. Repro: `type A struct{}; func (A) M() int { return 9 }; func main() { v := struct{ X interface{ M() int } }{A{}}; fmt.Println(v.X.M()) }` → got `internal compiler error: Cannot resolve struct for selector: M` on wasm, want `9`. (PR #281, wasm-struct-types Phase 2)
- **Parser:** A parenthesised pointer conversion over a composite type literal does not parse on any target. Repro: `func f[T any](x T) int { p := (*[]T)(nil); _ = p; return 0 }` → got `Parse error at 4:12: expected '{' (got ")")`, want it to compile (also `(*struct{ A T })(nil)`). (PR #284, wasm-struct-types Phase 3)
