- **JS shifts:** a negative runtime shift count gives a fractional result instead of a panic. Repro: `var x int = 1; n := -1; return int64(x << n)` → got `0.5` path (2**-1), want panic `negative shift amount`. (PR #41, portable-go Phase 0.11, Low)
- **Const shifts:** `const c = 1 << -1` reports two errors. Repro: `const c = 1 << -1` → got `invalid shift count: -1 is negative` and `invalid shift count: negative shift count`, want one. (PR #41, portable-go Phase 0.11, Low)
- **JS shifts:** a constant count below 32 keeps the 32-bit operator even for int64/int. Repro: `var x int64 = 1<<40; return (x << 3) + (x >> 3)` → got JS `0`, want `8933531975680`. (PR #41, portable-go Phase 0.11, Out of Scope)
- **JS shifts:** int64 `<<` overflow is not wrapped to 64 bits. Repro: `var x int64 = 3; n := 62; return x << n` → got JS `13835058055282164000`, want `-4611686018427387904`. (PR #41, portable-go Phase 0.11, Out of Scope)
- **JS ints:** unary `-` on int8 does not wrap. Repro: `var a int8 = -128; return int64(-a)` → got JS `128`, want `-128`. (PR #41, portable-go Phase 0.11, Out of Scope)
- **Typechecker:** shift of a float64 operand is accepted. Repro: `var f float64 = 1; y := f << 2` → got no error, want `shifted operand must be integer`. (PR #41, portable-go Phase 0.11, Out of Scope)
- **JS unsigned:** `-uint16(c+1)` on a typed const fails. Repro: `const c uint16 = 3; var v = -uint16(c+1)` → got `JS compile failed`, want `65532`. (PR #41, portable-go Phase 0.11, Out of Scope)
- **JS unsigned:** unary `^`/`-` on uint/uint64/uintptr do not wrap (Number cannot hold 64 bits). Repro: `var u uint64 = 1; return -u` → got negative Number, want `18446744073709551615`. (PR #41, portable-go Phase 0.11, Out of Scope)
- **WASM fmt:** `fmt.Println(args...)` with `args []any` fails WASM validation. Repro: `args := []any{"x", 1}; fmt.Println(args...)` in a `both`-target `Main` → got `WebAssembly.validate failed: call[1] expected type externref, found local.tee of type anyref`, want it to compile and print `x 1`. (feat/portable-go-phase-0.12, portable-go Phase 0.12 Task 0.25, Out of Scope)
- **Embedded structs (JS):** `Out{In: In{3}}` with a positional inner literal fails to compile. Repro: `type In struct{A int}; type Out struct{In}; o := Out{In: In{3}}` → got `CodeGen: unhandled expression kind 'undefined'`, want a compiled struct with `o.A == 3`. (feat/portable-go-phase-0.12, portable-go Phase 0.12 Task 0.27, Out of Scope)
- **WASM fmt:** struct-keyed map keys print in insertion order, not Go's sorted order. Repro: `fmt.Sprint(map[K]int{K{2}: 2, K{1}: 3})` with `type K struct{A int}` → got WASM `map[{2}:2 {1}:3]`, want `map[{1}:3 {2}:2]`. (feat/portable-go-phase-0.12, portable-go Phase 0.12 Task 0.27, Out of Scope)
- **WASM globals:** taking the address of a package-level scalar silently writes nowhere. Repro: `var x int; func Main() int { p := &x; *p = 5; return x }` (both-target) → got WASM `0`, want `5`; the same goes for a pointer-receiver call on a package-level named scalar (`var g C; g.Inc(); g.Inc(); int(g)` → got WASM `0`, want `2`). (feat/portable-go-phase-0.12, portable-go Phase 0.12 Task 0.28, Out of Scope)
- **JS struct map keys:** keys are compared and ordered by their `%v` text, so strings with spaces or uppercase sort wrongly and distinct keys can collide; ranging yields strings. Repro: `type T struct{X,Y string}; len(map[T]int{T{"x y","z"}:1, T{"x","y z"}:2})` → got `1`, want `2`; `fmt.Println(map[K]int{K{"a",5}:1, K{"a 1",0}:2})` → got `map[{a 1 0}:2 {a 5}:1]`, want `map[{a 5}:1 {a 1 0}:2]`. (PR #42, portable-go Phase 0.12, Low)
- **JS variadic spread:** `f(xs...)` copies when the callee is a closure, func value or interface method. Repro: `set := func(xs ...int){ xs[0] = -1 }; f := a[1:]; set(f...)` → got `a` unchanged, want `a[1] == -1`. (PR #42, portable-go Phase 0.12, Low)
- **JS variadic nil:** a variadic call with no arguments gives a non-nil slice. Repro: `func nilp(xs ...int) bool { return xs == nil }; nilp()` → got `false`, want `true`. (PR #42, portable-go Phase 0.12, Out of Scope)
- **JS fmt spread:** `fmt.Println(args...)` with `args []any` prints the slice. Repro: `args := []any{"x",1}; fmt.Println(args...)` → got `[x 1]`, want `x 1`; `fmt.Printf("%d %d\n", []any{1,2}...)` → got `NaN NaN`, want `1 2`. (PR #42, portable-go Phase 0.12, Out of Scope)
- **WASM globals:** package-level arrays of structs/arrays above 64 elements, and structs with array fields, are not zero-initialised. Repro: `type P struct{A,B int}; var big [100]P; func Main() int { return big[99].B }` (both target) → got nil-pointer trap, want `0`; `type Q struct{X [3]int}; var q Q; Main() { return q.X[1] }` → same. (PR #42, portable-go Phase 0.12, Low)
- **JS generics:** `==` on `any` type argument holding structs is false, and `var z T` is nil in erased code. Repro: `eq[any](P{1}, P{1})` → got `false`, want `true`; `func mut[T any](xs ...T){ var z T; xs[0] = z }; mut(c...)` with `[]int` → got `[<nil> 5]`, want `[0 5]`. (PR #42, portable-go Phase 0.12, Out of Scope)
- **JS fmt embedded struct:** printing a struct with an embedded field shows a stray extra field. Repro: `type Out struct{In; B int}; fmt.Println(Out{In{3},1})` → got `{{3} 1 0}`, want `{{3} 1}`. (PR #42, portable-go Phase 0.12, Out of Scope)
- **Typechecker:** promoted field through an embedded pointer two levels deep is not found. Repro: `type Deep2 struct{*Out}` (Out embeds In); `d.A = 4` → got `No field 'A' on Deep2`, want promoted access. (PR #42, portable-go Phase 0.12, Out of Scope)
- **JS composite literals:** a positional literal of an embedded struct inside a keyed outer literal crashes codegen. Repro: `type Base struct{n int}; type Outer struct{Base; v string}; Outer{Base: Base{7}, v: "x"}` → got `CodeGen: unhandled expression kind 'undefined'`, want a valid `Outer` (`Base{n: 7}` works). (branch feat/portable-go-phase-0.13, portable-go Phase 0.13, Out of Scope)
- **WASM embedding:** a pointer-receiver method promoted through an embedded pointer is not found. Repro: `type Base struct{n int}; func (b *Base) Inc() { b.n++ }; type Outer struct{*Base}; o := Outer{Base: &Base{n: 7}}; o.Inc()` (wasm target) → got `Unknown field 'Inc' on struct 'Outer'`, want `o.n == 8`. (branch feat/portable-go-phase-0.13, portable-go Phase 0.13, Out of Scope)
- **Typechecker:** a non-generic defined type over a named struct has no fields. Repro: `type Base struct{n int}; type S3 Base; func (s S3) N() int { return s.n }; S3{n: 5}.N()` → got `Cannot resolve struct for selector: n`, want `5`. (branch feat/portable-go-phase-0.13, portable-go Phase 0.13, Out of Scope)
- **Positional embedded literal:** `Outer{Base{7}, 2}` differs across backends. Repro: `type Base struct{n int}; type Outer struct{Base; v int}; o := Outer{Base{7}, 2}; o.n + o.v` → got JS 7 / WASM 9, want 9 on both. (PR #43, portable-go Phase 0.13, Out of Scope)
- **JS nil receivers:** method call on a nil pointer receiver throws. Repro: `func (l *List) Len() int { if l == nil {return 0}; return 1 + l.Next.Len() }; l := &List{1, &List{2, nil}}; l.Len()` → got `Cannot read properties of null (reading 'Len')`, want `2`. (PR #43, portable-go Phase 0.13, Out of Scope)
- **WASM embedding:** embedded `*Base` converted to an interface traps. Repro: `type O2 struct{ *Base; t string }` (Base has value method `N`); `var nm Namer = O2{Base: &Base{n: 3}}; nm.N()` → got `interface conversion: nil or unmatched type for method call`, want `3`. (PR #43, portable-go Phase 0.13, Out of Scope)
- **Generics:** same-named types from two packages collide as type arguments. Repro: `Box[a.Pt]{...}` and `Box[b.Pt]{...}` with different fields → got `No field 'X' on Pt`, want both compile. (PR #43, portable-go Phase 0.13, Out of Scope)
- **Generics:** infinitely expanding generic type overflows the stack. Repro: `type T[X any] struct{ n *T[[]X] }; var t T[int]` → got `Maximum call stack size exceeded`, want an instantiation-cycle diagnostic. (PR #43, portable-go Phase 0.13, Out of Scope)
- **Typechecker:** `type W V` with `V []int` crashes. Repro: `type V []int; type W V; var w W; len(w)` → got `Maximum call stack size exceeded`, want `0`. (PR #43, portable-go Phase 0.13, Out of Scope)
- **Generics:** generic function used as a value fails. Repro: `f := Id[int]; f(3)` → got `Undefined: 'int'`, want `3`. (PR #43, portable-go Phase 0.13, Out of Scope)
- **Generics:** explicit instantiation type mismatch not caught. Repro: `func Sum[T int|float64](xs ...T) T`; `return 3 + Sum[float64](1, 2)` in a func returning int → got JS 6 / WASM validate failure, want type error. (PR #43, portable-go Phase 0.13, Out of Scope)
- **Generics:** too many type arguments accepted. Repro: `util.Id[int, int](1)` → got compiles, want error. Also `strings.ToUpper[int]("a")` is now accepted since explicit args are dropped for non-generic emitter functions. (PR #43, portable-go Phase 0.13, Out of Scope)
- **Typechecker:** duplicate constant keys in a map literal accepted. Repro: `map[P]int{P{1}: 1, P{1}: 2}` → got returns 1, want duplicate key error. (PR #43, portable-go Phase 0.13, Out of Scope)
- **Generics:** method copying its generic receiver fails. Repro: `func (s Stack[T]) Copy() Stack[T] { c := s; return c }` → got `Cannot assign Stack to Stack[T]`, want compiles. (PR #43, portable-go Phase 0.13, Out of Scope)
- **Parser:** embedding an instantiated generic type fails. Repro: `struct { Inner[T]; w int }` → got `Parse error ... Expected type, got ';'`, want compiles. (PR #43, portable-go Phase 0.13, Out of Scope)
- **WASM generics:** `new(Stack[int])` fails. Repro: `new(Stack[int])` → got `Unresolved identifier: new`, want compiles. (PR #43, portable-go Phase 0.13, Out of Scope)
- **Parser:** array type argument in a type assertion fails. Repro: `x.(Stack[[2]int])` → got parse error, want compiles. (PR #43, portable-go Phase 0.13, Out of Scope)
- **Typechecker:** map literal with elided key against non-struct key type gives an internal message. Repro: `map[string]int{{1}: 1}` → got `Unknown struct in CompositeLit: string`, want an "invalid key type" style diagnostic. (PR #43, portable-go Phase 0.13, Low)
- **JS generics:** type-switch instantiation identity lost inside erased generic code. Repro: `func mk[T any]() any { return &Stack[T]{} }; mk[int]().(*Stack[string])` → got true on JS, want false. (PR #43, portable-go Phase 0.13, Low)
