- **WASM range assignment into an interface slice element:** A range assignment whose target is an element of an interface slice stores nothing in a `wasm` package. Repro: `out := make([]fmt.Stringer, 1); for _, out[0] = range []N{3, 4} {}; fmt.Println(out[0])` (`N` with a `String` method) → got `<nil>` on wasm, want `N4`. (feat/follow-ups-2026-11-11b-phase-5, follow-ups-2026-11-11b Phase 5, Out of Scope)
- **JS range-over-func into an interface:** A range-over-func loop that assigns its iteration variable to an interface-typed variable does not box a defined non-struct type with methods, so its methods are lost. Repro: `type N int; func (n N) String() string { return fmt.Sprintf("N%d", int(n)) }; func seq(yield func(N) bool) { yield(10) }; var s fmt.Stringer; for s = range seq {}; fmt.Println(s)` → got `10` (js), want `N10`. (PR #189, follow-ups-2026-11-11b Phase 5, Out of Scope)
- **JS defined slice nil after assertion:** Asserting a nil defined slice type out of an `any` returns the interface box instead of the nil slice, so the result does not compare equal to `nil`. Repro: `type S []int; var s S; var a any = s; ns, _ := a.(S); fmt.Println(ns == nil)` → got `false` (js), want `true`. (PR #190, follow-ups-2026-11-11b Phase 6, Out of Scope)
- **Generic arrays in an `any`:** An array whose element type is a type parameter, boxed into an `any` in generic code, prints `<nil>` and has an empty `%T` on every target (slices and maps are handled). Repro: `func mkArr[V any](v V) any { return [2]V{v, v} }; a := mkArr(5); fmt.Printf("%T %v\n", a, a)` → got ` <nil>`, want `[2]int [5 5]`. (PR #190, follow-ups-2026-11-11b Phase 6, Out of Scope)
- **WASM deferred variadic call:** `defer` of a call to a variadic function builds an invalid module in a `wasm` package, even with typed arguments. Repro: `func f(ys ...float64) { fmt.Println(ys) }; func main() { x := 4.0; defer f(x) }` → got invalid module (`array.new_fixed[0] expected type f64, found struct.new`), want `[4]`. (feat/follow-ups-2026-11-11b-phase-7, follow-ups-2026-11-11b Phase 7, Out of Scope)
