- **typechecker:** A value of type `any` is accepted where a struct is expected, and the WASM backend then emits an invalid module. Repro: `type A struct{N int}; func f(a A) int { return a.N }; func main() { var x any = A{3}; println(f(x)) }` in a `both` package → got `WebAssembly.validate failed: local.tee ... expected (ref null 0), found anyref`, want `Cannot use any as A`. (feat/overlays-to-go-phase-4, overlays-to-go Phase 4, Out of Scope)
- **js codegen:** A positional struct literal with `nil` for a map field stores `null`, so ranging over the field throws. Repro: `type S struct{a int; m map[string]int}; s := S{1, nil}; for range s.m {}` in a `both` package → got `TypeError: Cannot convert undefined or null to object`, want no iteration. (feat/overlays-to-go-phase-4, overlays-to-go Phase 4, Out of Scope)
- **WASM complex64:** Passing a `complex64` initialised from an untyped complex constant fails WebAssembly validation (emitted as `$complex128` into a `$complex64` local). Repro: `func f(c complex64) {}; func main() { var c64 complex64 = complex(1.5, 2.5); f(c64) }` in a wasm package → got `WebAssembly.validate failed: local.tee[0] expected type (ref null 26), found struct.new of type (ref 30)`, want it to compile. (PR #144, overlays-to-go Phase 4, Out of Scope)
- **WASM stdout:** Output written without a trailing newline is buffered and dropped when the program ends normally. Repro: `package main; import "fmt"; func main() { fmt.Print("hello") }` in a wasm package → got `""`, want `hello`. (PR #144, overlays-to-go Phase 4, Out of Scope)
- **CLI single file:** `gofront file.go -o out.js` compiles one file without the generated Go step, so `fmt` cannot describe a struct operand. Repro: `type P struct{X, Y int}; func main() { fmt.Println(P{1, 2}) }` in `b.go`, then `gofront b.go -o b.js && node b.js` → got `<nil>`, want `{1 2}` (a directory build prints `{1 2}`). (feat/overlays-to-go-phase-5, overlays-to-go Phase 5, Out of Scope)
- **fmt `%w` outside Errorf:** `%w` with an error operand in `Sprintf`/`Printf`/`Fprintf`/`Appendf` prints `%!w(=<nil>)` because `badVerb` writes the empty static type and skips methods. Repro: `fmt.Sprintf("%w", errors.New("e1"))` → got `%!w(=<nil>)`, want `%!w(*errors.errorString=&{e1})`. (PR #145, overlays-to-go Phase 5, Low)
- **testing sub-benchmarks:** `b.Run` runs the sub-benchmark once with `b.N == 1` and prints no row for it (same as before). Repro: `func BenchmarkX(b *testing.B) { b.Run("sub", func(b *testing.B) { for i := 0; i < b.N; i++ {} }) }` → got `b.N == 1` and no `BenchmarkX/sub` line, want iteration growth to the target duration and a result row. (PR #147, overlays-to-go Phase 7, Out of Scope)
