# Follow-ups

Bugs noticed outside the task at hand, each with a repro so it can be re-checked later. Written by `/dev-loop` reviewers and by any agent session. Open items only: `/design-plan follow-ups` re-probes them and moves each into a plan (as a fix task or a deferred row), deleting it here.

- **Untyped third-party imports:** an import with no resolvable types warns "treating as any" but any use of it is then rejected as undefined. Repro: `import "nope/zzz"; func main() { zzz.F() }` via `compileFiles` → got `warning: cannot find types for 'nope/zzz', treating as any` then `Type error … Undefined: 'zzz'`, want it to compile with `zzz` typed as `any` (or no "treating as any" claim). (design-plan review 2026-11-13, standalone, Out of Scope)
- **Named basic types:** a method-less named basic type named after a JS built-in is emitted as `class Map` and crashes at module load. Repro: `package main; import "fmt"; type Map int; func main() { var x Map = 5; fmt.Println(x) }` → got `ReferenceError: Cannot access 'Map' before initialization`, want `5`. (PR #203, js-codegen-fixes Phase 1, Out of Scope)
- **Method call on a variable named after its type:** a local or parameter whose name equals its named type compiles but the method call reads the class instead of the variable. Repro: `type T int; func (n T) Dbl() T { return n*2 }; func f() int { var T T = 4; return int(T.Dbl()) }` → got `T.$Dbl is not a function` at runtime, want `8` (base: `Too few arguments: expected 1, got 0`). (feat/js-codegen-fixes-phase-1, js-codegen-fixes Phase 1, Out of Scope)
- **Local type alias vs package value:** a function-local `type` declaration overwrites a package-level value or func of the same name for the whole package. Repro: `var __A = "hi"; func other() int { type __A = int; var x __A = 3; return x }; func Main() int { var s string = __A; return len(s) + other() }` → got `Cannot assign int to string`, want `5`. (PR #203, js-codegen-fixes Phase 1, Out of Scope)
- **`wasm` package `__` exports:** a `wasm` package exporting a `__`-prefixed func or var compiles but throws when a js main uses it. Repro: `//gofront:target wasm; package util; func __Answer() int { return 42 }` used as `util.__Answer()` from a js main → got `__Answer is not defined`, want `42` or a compile error. (PR #203, js-codegen-fixes Phase 1, Out of Scope)
- **Types named after strict-mode words:** `type yield struct{ X int }` (or `arguments`, `undefined`) emits a class that is a syntax error or shadows a global. Repro: `type yield struct{ X int }; func Main() int { return yield{X: 7}.X }` → got `Unexpected strict mode reserved word`, want `7`; `type undefined struct{X int}` with `a.(undefined)` → got `false`, want `true`. (PR #203, js-codegen-fixes Phase 1, Out of Scope)
- **Type parameter shadowing a package struct:** `new(T)` where the type parameter has the name of a package-level struct builds the struct. Repro: `type __S struct{ X int }; func f[__S any](v __S) *__S { return new(__S) }; func Main() int { return *f[int](3) }` → got `{"X":0}` text, want `0`. (PR #203, js-codegen-fixes Phase 1, Out of Scope)
- **`wasm` generic `(*T)(nil)`:** `(*Proxy)(nil)` inside a generic function fails to compile on `wasm`. Repro: `func f[Proxy comparable](x Proxy) int { p := (*Proxy)(nil); if p == nil { return 0 }; return 1 }` with `forceTarget` `wasm` → got `WASM compile failed`, want `0`. (PR #203, js-codegen-fixes Phase 1, Out of Scope)
- **Blank targets in multi-assignment (JS):** `_, x = a(), b()` evaluates the right side twice, and an all-blank `_, _ = a(), b()` drops the trailing expressions. Repro: `_, arr[t("i",0)] = t("x",5), t("y",6)` → got trace `ixyy` (`xyiy` on 1.9.2), want `ixy`; `_, _ = t("x",5), t("y",6)` → got `x`, want `xy`. (PR #204, js-codegen-fixes Phase 2, Out of Scope)
- **Comma-ok forms and assignment order:** with a comma-ok type assertion or map lookup on the right, target operands run after the right side on every target. Repro: `arr[t("i",0)], ok = fv().(int)` → got `fi`, want `if`; `arr[t("i",0)], ok = m[t("k",1)]` → got `ki`, want `ik`. (PR #204, js-codegen-fixes Phase 2, Out of Scope)
- **Assignment order in rarer JS forms:** a reslice-synced target, a generic `*p` target and a multi-assignment in a `for` post statement still evaluate the right side before the target operands. Repro: `for k := 0; k < 1; k, arr[t("i",0)] = t("x",1), t("y",6) {}` → got `xyi`, want `ixy`; in `func run[T any]`, `*pn("p", p), arr[ti("i",0)] = t("x",v1), t("y",v2)` → got `xypi`, want `pixy`. (PR #204, js-codegen-fixes Phase 2, Out of Scope)
- **Target read before call in compound assignment:** `+=` on every target, and `%=`, `<<=`, `>>=` on `js` and `wasm` (also `/=` on `wasm`), read the target before a right-hand call that mutates it. Repro: `var x int32 = 100; next := func() int32 { x = 200; return 2 }; x += next()` → got `102`, want `202`; `x /= next()` on `wasm` → got `50`, want `100`. (PR #204, js-codegen-fixes Phase 2, Out of Scope)
- **Struct pointer target in multi-assignment (JS):** `*ps("p", s), arr[t("i",0)] = S{5}, t("y",6)` → got `SyntaxError: Invalid destructuring assignment target` on `js` and `both`, want `piy 5 6`. (PR #204, js-codegen-fixes Phase 2, Out of Scope)
- **JS alias of an anonymous struct:** `type T = struct{ A [2]int }` is emitted as an empty `class T`, so a `T` value has no fields. Repro: `type T = struct{ A [2]int }; func main() { var s T; s.A[0] = 1; fmt.Println(s.A[0]) }` → got `Cannot set properties of undefined (setting '0')`, want `1`. (feat/js-codegen-fixes-phase-3, js-codegen-fixes Phase 3, Out of Scope)
- **Anonymous struct copies that stay shallow (JS):** copies of an anonymous struct that has an embedded field or a defined-array field (`type Vec [2]int`) or a type-parameter array field, a range-over-func yielded value, and a type-switch case binding still share array fields. Repro: `type P struct{ A [2]int }; st := struct{ P; B [2]int }{}; cp := st; cp.P.A[0] = 7; fmt.Println(st.P.A[0], cp.P.A[0])` → got `7 7`, want `0 7`; `type Vec [2]int; func f(s struct{ V Vec }) { s.V[0] = 9 }; s := struct{ V Vec }{}; f(s); fmt.Println(s.V[0])` → got `9`, want `0`. (PR #205, js-codegen-fixes Phase 3, Out of Scope)
- **Generic copy of a bare map or typed array (JS):** `dup[T any]` over a map clones it, and over `[N]byte` throws. Repro: `func dup[T any](v T) (T, T) { return v, v }; m := map[string]int{"a": 1}; x, y := dup(m); x["a"] = 9; fmt.Println(m["a"], x["a"], y["a"])` → got `1 9 1`, want `9 9 9`; `x, _ := dup([4]byte{1,2,3,4}); fmt.Println(len(x))` → got `TypeError`, want `4`. (PR #205, js-codegen-fixes Phase 3, Out of Scope)
- **`wasm` anonymous struct gaps:** an embedded field initialised in an anonymous struct literal is dropped, and a map keyed by an anonymous struct returns a stale value. Repro: `type P struct{ N int }; v := struct{ P; M int }{P: P{5}, M: 6}; fmt.Println(v.N, v.P.N, v.M)` → got `0 5 6`, want `5 5 6`. (PR #205, js-codegen-fixes Phase 3, Out of Scope)
- **Conversion to an anonymous struct type:** `struct{ A [2]int }(s)` fails to parse. Repro: `type S struct{ A [2]int }; s := S{[2]int{1, 2}}; var a any = struct{ A [2]int }(s)` → got `Parse error at 6:32: expected '{'`, want it to compile. (PR #205, js-codegen-fixes Phase 3, Out of Scope)
- **`wasm` slice bounds wrap to 32 bits:** a slice or string bound of 2^32 or more is truncated to `i32` before the check, so it can pass instead of panicking. Repro: `xs := []int{1, 2, 3}; n := 1 << 32; _ = xs[:n]` → got no panic, want `slice bounds out of range [:4294967296] with capacity 3`. (feat/js-codegen-fixes-phase-4, js-codegen-fixes Phase 4, Out of Scope)
- **Uncaught `wasm` panic text:** an uncaught panic of a bool, a large unsigned number, an error or a struct reaches JS with the wrong message. Repro: `func Main() { panic(true) }` on `wasm` → got `Error: 1`, want `Error: true`; `panic(uint64(1) << 63)` → got `Error: -9223372036854775808`, want `Error: 9223372036854775808`; `panic(errors.New("bad"))` → got `Error: [panic object]`, want `Error: bad`. (PR #206, js-codegen-fixes Phase 4, Out of Scope)
- **`panic(nil)` on `wasm`:** compiles but traps instead of panicking with a nil-panic error. Repro: `defer func() { fmt.Printf("%T %v\n", recover(), recover()) }(); panic(nil)` on `wasm` → got `RuntimeError: illegal cast`, want `*runtime.PanicNilError panic called with nil argument`. (PR #206, js-codegen-fixes Phase 4, Out of Scope)
- **`uint32` bounds of 2^31 or more on `wasm`:** index and slice-bounds panics print the value as negative. Repro: `xs := make([]int, 3, 5); u32 := uint32(1) << 31; _ = xs[:u32]` on `wasm` → got `slice bounds out of range [:-2147483648]`, want `[:2147483648] with capacity 5`; `_ = xs[u32]` → got `index out of range [-2147483648]`, want `index out of range [2147483648] with length 3`. (PR #206, js-codegen-fixes Phase 4, Low)
- **Generic struct instantiated with different anonymous structs:** the checker treats `Box[struct{ X int }]` and `Box[struct{ S string }]` as one instance. Repro: `type Box[T any] struct{ V T }; a := Box[struct{ X int }]{}; b := Box[struct{ S string }]{}; fmt.Println(a.V.X, b.V.S)` → got `Type error: No field 'S' on struct{...}`, want `0 ` (empty string after the space). (feat/js-codegen-fixes-phase-5, js-codegen-fixes Phase 5, Out of Scope)
- **`var` of an alias of an anonymous struct (JS):** the zero value is built with `new S()`, but an alias has no class. Repro: `type S = struct{ A [2]int }; var s S; fmt.Println(s.A[0])` → got `TypeError: S is not a constructor`, want `0`. (feat/js-codegen-fixes-phase-5, js-codegen-fixes Phase 5, Out of Scope)
- **Anonymous struct type in explicit type arguments:** `id[struct{ N int }](v)` fails to parse. Repro: `func id[T any](v T) T { return v }; x := id[struct{ N int }](struct{ N int }{4}); fmt.Println(x.N)` → got `Parse error: expected '{' (got ] "]")`, want `4`. (feat/js-codegen-fixes-phase-5, js-codegen-fixes Phase 5, Out of Scope)
- **`wasm` anonymous struct with an embedded struct:** a struct that embeds a named struct and also has a pointer field builds an invalid module. Repro: `type P struct{ N int }; y := struct{ P; M *P }{P{1}, &P{2}}; y.N = 5; fmt.Println(y.N, y.M.N)` on `wasm` → got `WebAssembly.validate failed: struct.new[1] expected type i64`, want `5 2`. (feat/js-codegen-fixes-phase-5, js-codegen-fixes Phase 5, Out of Scope)
- **Typed nil pointer calling a `__` method (JS):** a typed nil `*V` boxed in an interface calling a `__`-prefixed method neither panics nor passes `null`, because `__mknil` skips prototype methods starting with `__`. Repro: `type I interface{ __ref() int }; type V struct{ N int }; func (v V) __ref() int { return v.N }; var vp *V = nil; var i I = vp; i.__ref()` → got `-9223372036854775808`, want a nil-dereference panic. (PR #207, js-codegen-fixes Phase 5, Out of Scope)
- **`wasm` facade members named `__ref`/`__clone`:** a `wasm` struct declaring a field `__ref` recurses forever when read from JS. Repro: `//gofront:target wasm` `type S struct{ __ref int; N int }` read as `s.__ref` from a js main → got `RangeError: Maximum call stack size exceeded`, want `7`. (PR #207, js-codegen-fixes Phase 5, Out of Scope)
- **`wasm` map keyed by an anonymous struct with an array field:** lookups return the zero value. Repro: `a := struct{ X int; S string; A [2]int }{1, "x", [2]int{2, 3}}; m := map[struct{ X int; S string; A [2]int }]int{a: 10}; fmt.Println(m[a])` on `wasm` → got `0`, want `10`. (PR #207, js-codegen-fixes Phase 5, Out of Scope)
- **Unexported method of a `wasm` struct called from another package:** the checker accepts it and the JS facade has no such method. Repro: `//gofront:target wasm` `package util` with `type Rec struct{ N int }; func (r Rec) twice() int { return r.N * 2 }; func New(n int) *Rec { return &Rec{N: n} }`, then `util.New(7).twice()` from a js main → got `TypeError: r.twice is not a function`, want a compile error. (PR #207, js-codegen-fixes Phase 5, Out of Scope)
