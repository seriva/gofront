# Follow-ups

Bugs noticed outside the task at hand, each with a repro so it can be re-checked later. Written by `/bs-loop` reviewers and by any agent session. Open items only: `/bs-plan follow-ups` re-probes them, groups them by root cause, and moves each into a plan (as a fix task or a deferred row), deleting it here.

Each entry names its root cause (the mechanism that produces it, not the path that exposed it) and its route: the open plan whose scope covers that root, or `unrouted`. Entries with the same root sit together. A defect with the same root as the task being fixed is part of that task and never lands here (`/bs-loop` **Follow-ups**).

- **Too-few forwarded return values position:** `not enough return values` for `return f()` reports at `return` instead of the forwarded call. Root: `forwarded-tuple` (`src/typechecker/statements.js:_reportReturnCount` passes `stmt` in the `!many` branch, `stmt.values[0]` in the `many` branch). Repro: `func pair() (int, string) { return 1, "a" }; func three() (int, string, bool) {\n\treturn pair()\n}` → got `4:2`, want `4:9` (Go reports at `pair()`). (PR #244, checker-go-rules Phase 11, Low) → checker-go-rules
- **Builtins on forwarded tuples:** `min`, `complex`, `copy` and `delete` do not unpack a multi-value call argument. Root: `builtin-multi-forward` (`src/typechecker/expressions.js` builtin checks read `expr.args` before `_multiForward` unpacking). Repro: `func f() (int, int) { return 1, 2 }; func main() { _ = min(f()) }` → got `invalid argument: f() (value of type (int, int)) cannot be ordered`, want accepted (Go accepts). (PR #244, checker-go-rules Phase 11, Out of Scope) → unrouted
- **Forwarded struct literal to identical defined struct:** a forwarded element of identical struct type is rejected for a defined struct parameter. Root: `struct-copy-multi-forward` (`src/typechecker/assignability.js:_markStructCopy` cannot rewrite one element inside a multi-value call). Repro: `type S struct{ X int }; func f() (struct{ X int }, int) { return struct{ X int }{1}, 2 }; func g(a S, b int) {}; func main() { g(f()) }` → got `Cannot assign struct{...} to S here: convert it explicitly with S(v)`, want accepted (Go accepts). (PR #244, checker-go-rules Phase 11, Out of Scope) → unrouted
- **Range assignment over non-iterator func:** `for x = range fn` over a non-iterator func also reports a spurious assignment error. Root: `range-invalid-func-cascade` (`src/typechecker/statements.js:_checkForStmt` falls through to `checkStmt(stmt.init)` after `_checkRangeIterStmt` rejects the func and returns `null`). Repro: `func fn(int) {}; func main() { var x int; for x = range fn { _ = x } }` → got `cannot range over func: not an iterator function` plus `Cannot assign func(int) void to int`, want only the first. (PR #245, checker-go-rules Phase 12, Out of Scope) → unrouted
- **Type switch blank binding:** `switch _ := v.(type)` is accepted. Root: `typeswitch-blank-lhs` (`src/parser/statements.js:_parseTypeSwitchBody` and `src/typechecker/statements.js:_checkTypeSwitchStmt` do not reject `_`). Repro: `func f(v any) { switch _ := v.(type) { case int: } }` → got no error, want `no new variable on left side of :=`. (PR #245, checker-go-rules Phase 12, Out of Scope) → unrouted
- **Unused type switch binding:** an unused type-switch binding is not reported. Root: `typeswitch-unused-binding` (`src/typechecker/statements.js:_checkTypeSwitchStmt` unconditionally calls `caseScope.lookup(stmt.assign)`, marking it used). Repro: `func f(v any) { switch x := v.(type) { case int: } }` → got no error, want `declared and not used: x`. (PR #245, checker-go-rules Phase 12, Out of Scope) → unrouted
- **Inline union constraint text:** a diagnostic about a type parameter whose constraint is an inline union names the constraint `?`. Root: `constraint-text` (`src/typechecker/assignability.js:_constraintText` falls through to `typeStr`, which has no spelling for an inline union constraint). Repro: `func M[T ~int | ~float64](a, b T) T { return a % b }` → got `operator % not defined on a (variable of type T constrained by ?)`, want `… constrained by ~int | ~float64`. (feat/checker-go-rules-phase-14, checker-go-rules Phase 14, Out of Scope) → unrouted
