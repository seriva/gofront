- **WASM range assignment:** assigning a slice range index to a declared `any` variable builds an invalid WebAssembly module. Repro: `var a any; for a = range []int{5, 6} {}; fmt.Println(a)` → got wasm `local.set[0] expected type anyref, found local.get of type i32`, want `1`. (feat/follow-ups-2026-11-11-phase-1, follow-ups-2026-11-11 Phase 1, Out of Scope)
- **Typechecker struct embeds:** a struct embedding a user-declared interface does not get the interface's methods. Repro: `type Mer interface{ M() }; type T struct{}; func (T) M() {}; type S struct{ Mer }; var m Mer = S{T{}}; S{T{}}.M()` → got `S does not implement Mer` and `No field 'M' on S`, want it to compile and call `T.M`. (feat/follow-ups-2026-11-11-phase-2, follow-ups-2026-11-11 Phase 2, Out of Scope)
- **Typechecker promoted fields:** a promoted field and a promoted method with the same name at the same depth resolve to the field instead of being ambiguous. Repro: `type A struct{ M int }; type B struct{}; func (B) M() {}; type C struct{ A; B }; c := C{}; fmt.Println(c.M)` → got `0`, want `ambiguous selector c.M`. (feat/follow-ups-2026-11-11-phase-2, follow-ups-2026-11-11 Phase 2, Out of Scope)
- **WASM nil embedded pointer:** a promoted value-receiver method reached through a nil embedded pointer in an interface runs instead of panicking on WebAssembly. Repro: `type VMer interface{ VM() }; type Inner struct{}; func (i Inner) VM() { fmt.Println("inner") }; type PO struct{ *Inner }; var v any = PO{}; v.(VMer).VM()` with `recover` → got wasm `inner`, want `runtime error: invalid memory address or nil pointer dereference`. (#181, follow-ups-2026-11-11 Phase 2, Out of Scope)
- **WASM array identity in `any`:** arrays with the same element wasm type are not told apart by type in an `any` on WebAssembly, so a named array matches the unnamed type in assertions and `==`. Repro: `type A [2]int; var k any = A{1, 2}; _, ok := k.([2]int); var j any = [2]int{1, 2}; fmt.Println(ok, k == j)` → got wasm `true true`, want `false false`. (feat/follow-ups-2026-11-11-phase-3, follow-ups-2026-11-11 Phase 3, Out of Scope)
- **Parser type arguments:** an explicit func type argument in a call does not parse. Repro: `func mk[V any]() any { return map[string]V{} }; w := mk[func(int)]()` → got `Parse error … Expected type, got ']'`, want it to compile. (feat/follow-ups-2026-11-11-phase-3, follow-ups-2026-11-11 Phase 3, Out of Scope)
- **WASM generic maps of funcs:** a map with func values built in generic code and stored in an `any` does not match its type on WebAssembly. Repro: `func mk[V any](v V) any { return map[string]V{} }; w := mk(func() {}); _, ok := w.(map[string]func()); fmt.Printf("%T %v\n", w, ok)` → got wasm ` false`, want `map[string]func() true`. (feat/follow-ups-2026-11-11-phase-3, follow-ups-2026-11-11 Phase 3, Out of Scope)
- **WASM assertion panic names:** a failed type assertion on an array or a slice of funcs in an `any` names the wrong dynamic type on WebAssembly. Repro: `var w any = [2]int{}; _ = w.(int)` with `recover` → got wasm `interface conversion: interface {} is interface {}, not int`, want `… is [2]int, not int` (also `[]func(){}` → `[]interface {}`). (feat/follow-ups-2026-11-11-phase-3, follow-ups-2026-11-11 Phase 3, Out of Scope)
- **WASM labeled `range` over int with an inner iterator:** `continue L` to a labeled `for i := range n` loop from inside a nested range-over-func loop builds an invalid module on WebAssembly. Repro: `L5: for i := range 2 { for x := range seq { if x == 2 { continue L5 }; fmt.Println(i, x) } }` with a 3-value `seq` → got wasm `struct.new[1] expected type i64, found local.get of type i32`, want `0 1
1 1` (js correct). (feat/follow-ups-2026-11-11-phase-4, follow-ups-2026-11-11 Phase 4, Out of Scope)
- **JS forwarded call into an interface method:** a multi-value call forwarded into an interface method call nested in a larger expression loses the struct's type in a `both` package. Repro: `type C interface{ check(v any, n int) bool }; var c C = &O{}; fmt.Println(wrap(c.check(makePair())))` with `makePair() (T, int)` and `check` asserting `v.(T)` → got both `false`, want `true` (js and wasm correct; `x := c.check(makePair())` correct). (feat/follow-ups-2026-11-11-phase-4, follow-ups-2026-11-11 Phase 4, Out of Scope)
