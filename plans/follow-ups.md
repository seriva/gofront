- **Typechecker conversions:** Calling an alias of an anonymous struct type as a conversion is rejected. - **Parser:** A struct type with a field tag inside generic type arguments does not parse. Repro: `type Box[T any] struct{ V T }; var c Box[struct{ X int `json:"x"` }]` → got `Parse error at 3:10: Expected top-level declaration (got [ "[")`, want it to compile. (feat/follow-ups-2026-11-16-phase-1, follow-ups-2026-11-16 Phase 1, Out of Scope)
- **Typechecker generics:** Grouped and ungrouped field declarations of the same anonymous struct get separate generic instances. Repro: `type Box[T any] struct{ V T }; a := Box[struct{ X, Y int }]{}; b := Box[struct{ X int; Y int }]{}; fmt.Printf("%T %T\n", a, b)` → got `main.Box[struct { X, Y int }] main.Box[struct { X int; Y int }]`, want identical types. (feat/follow-ups-2026-11-16-phase-1, follow-ups-2026-11-16 Phase 1, Low)
- **Parser:** A parenthesised anonymous struct type conversion does not parse. Repro: `type S struct{ A [2]int }; s := S{}; u := (struct{ A [2]int })(s)` → got `Parse error at 7:26: expected '{' (got ) ")")`, want a converted value. (feat/follow-ups-2026-11-16-phase-1, follow-ups-2026-11-16 Phase 1, Out of Scope)
- **Local types:** A function-local type named after an imported package takes over the import in other functions. Repro: `import ("fmt"; "strings"); func other() int { type strings = int; var x strings = 3; return x }; func main() { fmt.Println(other(), strings.ToUpper("ab")) }` → got `int has no field or method 'ToUpper'`, want `3 AB`. (feat/follow-ups-2026-11-16-phase-1, follow-ups-2026-11-16 Phase 1, Out of Scope)
- **Typechecker generics:** Generic instances over func or interface types that mention different anonymous structs collide. Repro: `type Box[T any] struct{ V T }; a := Box[func(struct{ X int })]{V: func(s struct{ X int }) { fmt.Println(s.X) }}; var b Box[func(struct{ S string })] = a; b.V(struct{ S string }{"hi"})` → got `-9223372036854775808`, want a compile error. (feat/follow-ups-2026-11-16-phase-1, follow-ups-2026-11-16 Phase 1, Out of Scope)
- **JS value semantics:** Copying a plain embedded anonymous struct shares the embedded struct's storage. Repro: `type P struct{ N int }; v := struct{ P }{P{3}}; w := v; w.P.N = 8; fmt.Println(v.N)` → got `8`, want `3`. (feat/follow-ups-2026-11-16-phase-1, follow-ups-2026-11-16 Phase 1, Out of Scope)
- **Untyped npm imports:** An unused or `.`-aliased untyped npm import in a `wasm`/`both` package compiles silently, while `import _` is rejected. Repro: `//gofront:target wasm` + `import "nope/zzz"; func main() { println("ok") }` → got compiles, want `'zzz' imported and not used` or `js: imports are not allowed in wasm packages`. (PR #210, follow-ups-2026-11-16 Phase 2, Low)
- **Untyped npm imports:** A qualified type from an untyped import in a `wasm` package reports `Unknown type` instead of the JS-only error. Repro: `//gofront:target wasm` + `import "nope/zzz"; func main() { var x zzz.T; _ = x }` → got `Unknown type 'zzz.T'`, want `'zzz' is only available in js packages`. (PR #210, follow-ups-2026-11-16 Phase 2, Low)
- **Package exports:** Uppercase imported globals leak through `getExportedSymbols` as members of a sub-package. Repro: `sub/sub.go` `package sub; import "mydep"; func Use() any { return Bar }` with `export declare const Bar: number;` in `mydep`, main `println(sub.Bar)` → got compiles and emits `console.log(Bar)`, want compile error (`sub` has no `Bar`). (PR #210, follow-ups-2026-11-16 Phase 2, Out of Scope)
- **WASM emitter:** A composite literal of a qualified name on a non-package global crashes the emitter. Repro: `//gofront:target wasm` + `func main() { _ = console.T{} }` → got `Error: Unknown struct in CompositeLit: any`, want a type error. (PR #210, follow-ups-2026-11-16 Phase 2, Out of Scope)
- **Imports:** npm import bindings are package-wide, not per file. Repro: `a.go` `import "nope/zzz"; func f() { zzz.F() }`, `b.go` `func main() { zzz.G() }` → got compiles, want `Undefined: 'zzz'` in `b.go`. (PR #210, follow-ups-2026-11-16 Phase 2, Out of Scope)
- **WebAssembly generic over anonymous struct:** `*f[struct{ X int }](...)` of a `func f[T any](v T) *T` fails to compile on wasm, and with a package struct named like the type parameter `f[struct{ X int }](...).X` fails with `Cannot resolve struct for selector: X`. Repro: `type S struct{X int}; func f[S any](v S) *S { return new(S) }; fmt.Println(f[struct{ X int }](struct{ X int }{}).X)` on wasm → got `Cannot resolve struct for selector: X`, want `0`. (feat/follow-ups-2026-11-16-phase-3, follow-ups-2026-11-16 Phase 3, Out of Scope)
- **WASM facade:** The facade emits an unescaped `class` name for strict-mode reserved struct names. Repro: `//gofront:target wasm` + `type yield struct{ X int }; func (y *yield) IsNil() bool { return y == nil }; type Outer struct{ *yield }; func main() { var o Outer; fmt.Println(o.IsNil()) }` → got `SyntaxError: Unexpected strict mode reserved word`, want `true`. (PR #211, follow-ups-2026-11-16 Phase 3, Out of Scope)
- **WASM method expressions:** A pointer method expression on a struct pointer does not compile. Repro: `//gofront:target wasm` + `type undefined struct{ X int }; func (u *undefined) IsNil() bool { return u == nil }; func main() { fmt.Println((*undefined).IsNil(nil)) }` → got `Compile error: Cannot resolve struct for selector: IsNil`, want `true`. (PR #211, follow-ups-2026-11-16 Phase 3, Out of Scope)
- **Comma-ok `:=` map index (JS non-strict):** The key expression of `v, ok := m[f()]` is emitted twice, so a call in the key runs twice. Repro: `ks := func(k string) string { trace += "k"; return k }; m := map[string]int{"k": 4}; v, ok := m[ks("k")]; fmt.Println(trace, v, ok)` on the js package target → got `kk 4 true`, want `k 4 true`. (feat/follow-ups-2026-11-16-phase-4, follow-ups-2026-11-16 Phase 4, Out of Scope)
- **JS complex compound assignment:** `c += f()` on a complex target evaluates the call twice and reads the target before it. Repro: `calls := 0; c := complex(1, 2); f := func() complex128 { calls++; c = complex(10, 20); return complex(3, 4) }; c += f(); fmt.Println(calls, c)` → got `2 (4+24i)` on js/both, want `1 (13+24i)`. (PR #212, follow-ups-2026-11-16 Phase 4, Out of Scope)
- **WASM compound assignment:** `x[i] op= f()` reads non-call target operands before the right-hand call. Repro: `i := 0; arr := []int{10, 20}; f := func() int { i = 1; return 5 }; arr[i] += f(); fmt.Println(arr, i)` → got `[15 20] 1` on wasm, want `[10 25] 1`. (PR #212, follow-ups-2026-11-16 Phase 4, Out of Scope)
- **JS comma-ok / stable tuple into `*p` struct:** Assigning a comma-ok or stable-tuple result into a `*p` struct pointer emits an invalid left-hand side. Repro: `type S struct{ f int }; p := &S{1}; m := map[string]S{"k": {5}}; var ok bool; *p, ok = m["k"]` → got `ReferenceError: Invalid left-hand side in assignment` on js/both, want `5 true`. (PR #212, follow-ups-2026-11-16 Phase 4, Out of Scope)
- **Multiple assignment order:** A regular multi-assignment reads a plain index variable before a right-hand call. Repro: `i := 0; arr := [2]int{}; fv := func() int { i = 1; return 4 }; var x int; arr[i], x = fv(), 5; fmt.Println(arr, x)` → got `[4 0] 5` on all targets, want `[0 4] 5`. (PR #212, follow-ups-2026-11-16 Phase 4, Out of Scope)
- **Multiple assignment aliasing:** `p, *p = &b, 99` stores through the old `p` in Go but the new one here. Repro: `a, b := 10, 20; p := &a; p, *p = &b, 99; fmt.Println(a, b, *p)` → got `10 99 99`, want `99 20 20`. (PR #212, follow-ups-2026-11-16 Phase 4, Out of Scope)
- **WASM struct assignment through `*p`:** `*p, x = s2, 9` aliases the source struct's array field. Repro: `type S struct{ A [2]int }; s1, s2 := S{}, S{[2]int{1, 2}}; p := &s1; var x int; *p, x = s2, 9; s2.A[0] = 99; fmt.Println(s1.A)` → got `[99 2]` on wasm, want `[1 2]`. (PR #212, follow-ups-2026-11-16 Phase 4, Out of Scope)
- **JS assignment order:** A `for`-post multi-assignment with a stable-tuple or generic `*p` target still reads a plain index variable before the right-hand call. Repro: `s := S{}; ps := &s; for k := 0; k < 1; s, arr[i], arr2[ti(0)], k = (S{5}), 9, 8, fv() {}` (`fv` sets `i = 1`) → js/both got `5 [9 0] [8 0] 1`, want `5 [0 9] [8 0] 1`; generic `for k := 0; k < 1; *ps(p), arr[i], k = v1, v2, fv() {}` → got `5 [9 0] 1`, want `5 [0 9] 1`. `_genStableTupleAssign` and `_genTypeParamDerefMultiAssign` do not pass the for-post call-only hoisting flag. (PR #212, follow-ups-2026-11-16 Phase 4, Low)
- **WASM compound assignment:** `x[i] op= f()`, `p.n op= f()`, `m[k] op= f()` and `*q op= f()` read plain `i`, `p`, `k`, `q` before a right-hand call that mutates them, unlike JS and Go. Repro: `i := 0; xs := []int{10, 20}; f := func() int { i = 1; return 5 }; xs[i] += f()` on wasm → got `[15 20] 1`, want `[10 25] 1`; `_emitCompoundAssign` calls `_hoistLhsOperands` without `callOnly`. (PR #212, follow-ups-2026-11-16 Phase 4, Low)
- **Assignment order (struct reassigned by RHS call):** Storing into a field or element of a struct variable whose right-hand call reassigns the whole struct writes into the old struct. Repro: `type S struct{ A [2]int; N int }; s := S{}; f := func() int { s = S{N: 4}; return 2 }; s.A[0] = f(); fmt.Println(s)` → got `{[0 0] 4}` on js/both/wasm, want `{[2 0] 4}`. (difffuzz order mode, standalone, Low)
- **JS anonymous struct alias:** `new(T)` where `T` is an alias of an anonymous struct wraps the zero value in `{ value }`, so reading a field crashes. Repro: `type T = struct{ A [2]int }; p := new(T); fmt.Println(p.A[0])` → got `TypeError: Cannot read properties of undefined (reading '0')`, want `0`. (PR #213, follow-ups-2026-11-16 Phase 5, Out of Scope)
- **JS range-over-func:** A sequence yielding a fixed-size array does not copy it into the loop variable. Repro: `arr := [2]int{1, 2}; seq := func(yield func([2]int) bool) { yield(arr) }; for v := range seq { v[0] = 9 }; fmt.Println(arr[0])` → got `9`, want `1`. (PR #213, follow-ups-2026-11-16 Phase 5, Out of Scope)
