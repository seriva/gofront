- **Templ css:** a parameterized `css` declaration now surfaces as an internal compiler error because `genCssDecl` in `src/backend/js/templ.js` throws a bare `Error`. Repro: `compileFiles(["main.templ"], { forceTarget: "js" })` with `css bad(x string) { color: red; }` → got `InternalCompilerError: internal compiler error: css bad: parameterized css declarations are not yet supported`, want a `CompileError` without the internal-error wrapper (throw `UnsupportedError`). (PR #225, checker-strictness Phase 1, Out of Scope)
- **compileWasm:** the standalone `compileWasm` helper returns wasm bytes without running `validateWasm`. Repro: `compileWasm("package main\nfunc main() {\n\tvar a struct{ X int }\n\tvar b struct{ Y string }\n\ta = b\n}\n")` → got `{ wasm: Uint8Array(273), errors: [] }` with `WebAssembly.validate(wasm) === false`, want `InternalCompilerError`. (PR #225, checker-strictness Phase 1, Out of Scope)
- **Positions:** `BasicLit` nodes that `parseConstDecl` substitutes for `iota` carry no `_line`/`_col` (129 nodes in `example/` + `stdlib/`). Repro: parse `example/gom/src/types.go`, walk `ConstDecl.value` `BasicLit` nodes → got `_line: undefined`, want the line:col of the `iota` token or its `ConstSpec`. (PR #225, checker-strictness Phase 1, Out of Scope)
- **Positions:** the type-switch capture variable is defined without a declaring node, so `localNode` returns null (benign today because it is marked used immediately). Repro: inspect `caseScope.localNode(stmt.assign)` in `_checkTypeSwitchStmt` for `switch x := v.(type)` → got `null`, want the declaring identifier node. (PR #225, checker-strictness Phase 1, Out of Scope)
- **WASM map keys:** map keys of unnamed struct type fail lookup on `wasm` (`_resolveStructType` in `src/backend/wasm/emit-maps.js`). Repro: `m := map[struct{ X int }]int{}; u := struct{ X int }{5}; m[u] = 10; fmt.Println(m[u])` → got `0` on `wasm`, want `10` (as on `js`/`both`). (PR #226, checker-strictness Phase 2, Out of Scope)
- **Assignability:** a pointer to a defined empty interface is assignable to `*any`. Repro: `type B interface{}; var p *B; var q *any = p; _ = q` → got no error on any target, want `Cannot assign *B to *any`. (PR #226, checker-strictness Phase 2, Out of Scope)
- **Struct conversion:** `_sameStructFields` in `src/typechecker/expressions.js` treats an embedded and a non-embedded field of the same name as convertible. Repro: `type E struct{ V int }; var a struct{ E }; b := struct{ E E }(a); fmt.Println(b.E.V)` → got `TypeError: Cannot read properties of undefined` on `js`/`both` and `InternalCompilerError` on `wasm`, want a `cannot convert` error. (PR #226, checker-strictness Phase 2, Out of Scope)
- **append:** `append` does not check element assignability. Repro: `var s []struct{ X int }; s = append(s, struct{ Y string }{"a"})` → got no error on any target and `InternalCompilerError` on `wasm`, want a compile error; same for `type A struct{ X int }; s = append(s, A{5})`. (PR #226, checker-strictness Phase 2, Out of Scope)
- **WASM struct conversion:** explicit conversion between a struct with an embedded field and an unnamed struct fails on `wasm`. Repro: `type E struct{ V int }; type A struct{ E }; a := A{E{11}}; u := struct{ E }(a); b := A(u)` → got `InternalCompilerError: the generated WebAssembly is invalid` on `wasm` (`11 11` on `js`/`both`), want `11 11`. (PR #226, checker-strictness Phase 2, Out of Scope)
- **Defined string types:** `_binaryResultTypeString` returns `string` rather than the operand type and does not check identical operands. Repro: `type S string; func main() { var a, b S = "x", "y"; var c S = a + b; _ = c }` → got `Cannot assign string to S`, want success; and `var s S = "a"; var t string = "b"; _ = s + t` → got success, want `mismatched types S and string`. (PR #227, checker-strictness Phase 3, Out of Scope)
- **Complex operands:** `_binaryResultTypeComplex` accepts an untyped complex constant with a float and returns `complex128` for defined complex types. Repro: `var f float64 = 1; _ = f + 1i` (`wasm`) → got `InternalCompilerError: invalid wasm`, want a compile error; `type MyC complex128; var a, b MyC = 1i, 2i; var c MyC = a + b` → got `Cannot assign complex128 to MyC`, want success. (PR #227, checker-strictness Phase 3, Out of Scope)
- **Shifts:** compound shifts bypass `_binaryResultTypeShift` and an untyped float shift count is not accepted on `wasm`. Repro: `var f float64 = 1.0; f <<= 1` (`wasm`) → got `InternalCompilerError: Unsupported WASM instruction opcode: 'f64.ge_u'`, want a compile error; `x := 1; _ = x << 1.0` (`wasm`) → got `InternalCompilerError: expected type i64, found f64.const`, want `2`. (PR #227, checker-strictness Phase 3, Out of Scope)
- **Untyped comparisons:** `_checkCmpOperandTypes` skips untyped operands so a string never compares with a rune or int constant. Repro: `s := "a"; _ = s == 'a'` (`wasm`) → got `InternalCompilerError`, want a compile error; same for `n := 1; _ = n == "a"`. (PR #227, checker-strictness Phase 3, Out of Scope)
- **Generics:** an invalid operator in a generic body is only found at instantiation and `monomorph.js` throws a plain `Error`. Repro: `type N interface{ ~int | ~float64 }; func M[T N](a, b T) T { return a % b }; func main() { _ = M(5.5, 2.0) }` (`wasm`) → got `InternalCompilerError: Type error ... operator % not defined`, want a `CompileError` (and on `js` a compile error at the definition). (PR #227, checker-strictness Phase 3, Out of Scope)
- **Diagnostics:** `_checkNumericCoercion` has no position for a forwarded multi-value call argument. Repro: `func f() (float64, float64) { return 1, 2 }; func g(a, b int) {}; func main() { g(f()) }` → got `cannot use expression (value of type float64) as int value in argument` with no line:col, want `at line 4:2`. (PR #227, checker-strictness Phase 3, Out of Scope)
- **Templ conditions:** `_checkTemplIf` and `_checkTemplCondAttr` in `src/typechecker/index.js` accept a Go `any` as a condition. Repro: `compileFiles(["main.templ"], { forceTarget: "js" })` on `templ Page(v any) { if v { <div hidden?={ v }>hi</div> } }` → got no diagnostics, want `non-boolean condition in if statement`. (PR #228, checker-strictness Phase 4, Low)
- **Slice index:** `"any"` is in `NON_INTEGER_BASICS`, so a JS-dynamic value cannot index a typed slice. Repro: `xs := []int{1, 2}; _ = xs[window.i]` (`js`) → got `invalid argument: index window.i (value of type any) must be integer`, want accepted (JS-dynamic stays permissive). (PR #228, checker-strictness Phase 4, Out of Scope)
- **Error recovery:** `_checkDeref` tests `ot === ANY` instead of `isAny(ot)`, so dereferencing a tainted value adds a second error. Repro: `v := missingVar; _ = *v` → got `Undefined: 'missingVar'` plus `cannot dereference non-pointer type any`, want only the first. (PR #228, checker-strictness Phase 4, Out of Scope)
- **Builtins on Go any:** `len`, `cap`, `append`, `copy`, `delete` and `f(v...)` accept a Go `any`. Repro: `var v any = []int{1}; _ = len(v)` (`wasm`) → got `InternalCompilerError: not enough arguments on the stack for i64.extend_i32_u`, want a `CompileError` rejecting `any` as the argument. (PR #228, checker-strictness Phase 4, Out of Scope)
- **Empty interface literal:** `interface{}` lacks the Go-`any` operator checks and `type MyAny any` rejects `var v MyAny = 2`. Repro: `var v interface{} = 2; for range v {}; v++` (`wasm`) → got `InternalCompilerError: Unsupported WASM instruction opcode: 'anyref.add'`, want compile errors as for `any`. (PR #228, checker-strictness Phase 4, Out of Scope)
- **Range over int, two variables:** `for i, v := range 3` is accepted; Go rejects it (`range over 3 (untyped int constant) permits only one iteration variable`). Repro: `for i, v := range 3 { fmt.Println(i, v) }` (`wasm`) → got `InternalCompilerError: Unresolved identifier: v` (`js`/`both` compile), want a `CompileError`. (branch feat/checker-strictness-phase-5, checker-strictness Phase 5, Out of Scope)
- **Range over a defined string type:** the rune of a range over `type Word string` prints as `�` on `js`. Repro: `type Word string; for i, r := range Word("ab") { fmt.Printf("%v:%c ", i, r) }` → got `0:� 1:�`, want `0:a 1:b`. (branch feat/checker-strictness-phase-5, checker-strictness Phase 5, Out of Scope)
- **Range over an untyped float constant:** `const k = 2.0; for i := range k { fmt.Println(i) }` compiles to invalid WebAssembly. Repro: that program (`wasm`) → got `InternalCompilerError: … call[1] expected type f64, found local.get of type i32`, want `0 1` (or a `CompileError` if Go rejects it). (branch feat/checker-strictness-phase-5, checker-strictness Phase 5, Out of Scope)
- **Pointer method on dereferenced named scalar:** `(*p).Inc()` with `Inc` on a pointer receiver of `type Num int` mutates a copy on `js`. Repro: `var x Num; p := &x; (*p).Inc(); fmt.Println(x)` → got `0`, want `1`. (branch feat/checker-strictness-phase-5, checker-strictness Phase 5, Out of Scope)
- **Return count:** a void function returning a multi-value call reports the wrong count. Repro: `func g() (int, string) { return 1, "a" }; func f() { return g() }` → got `too many return values (have 1, want 0)`, want `(have 2, want 0)`. (PR #229, checker-strictness Phase 5, Low)
- **Range over func types:** bare `for range fn` over a defined non-iterator func type is accepted because `_checkForCond` tests `ct?.kind === "func"` instead of the underlying type. Repro: `type MyFunc func(int); var fn MyFunc; for range fn {}` → got `OK` on `js`/`both` and `InternalCompilerError: Maximum call stack size exceeded` on `wasm`, want a `CompileError`. (PR #229, checker-strictness Phase 5, Out of Scope)
- **Positions:** `_checkRangeIterInvalidFunc` has no line:col. Repro: `func fn(int) {}; func main() { for x := range fn { _ = x } }` → got `cannot range over func: not an iterator function` without a position, want `at line N:col`. (PR #229, checker-strictness Phase 5, Out of Scope)
- **Assignment targets:** assigning to a field or element of a non-addressable value is accepted. Repro: `type P struct{ X int }; func mk() P { return P{} }; func main() { mk().X = 1; P{}.X = 1; [2]int{1, 2}[0] = 3 }` → got `OK` on all targets, want `cannot assign to ...`. (PR #229, checker-strictness Phase 5, Out of Scope)
- **nil comparison:** a struct can be compared with `nil`. Repro: `type P struct{ X int }; var p P; _ = p == nil` → got `OK` on all targets, want `mismatched types P and untyped nil`. (PR #229, checker-strictness Phase 5, Out of Scope)
- **Untyped nil:** `var x = nil` and `const c = nil` compile on `js`/`both` and give invalid WebAssembly on `wasm`. Repro: `func main() { var x = nil; const c = nil; _, _ = x, c }` → got `InternalCompilerError: the generated WebAssembly is invalid` on `wasm`, want `use of untyped nil in variable declaration`. (PR #229, checker-strictness Phase 5, Out of Scope)
- **Type parameter nil:** `nil` is assignable to any type parameter. Repro: `func f[T any]() T { var x T = nil; return x }` → got `OK` on all targets, want a compile error when `T` has no nilable core type. (PR #229, checker-strictness Phase 5, Out of Scope)
- **JS codegen:** a discarded map literal with computed keys is emitted as a statement that starts with `{`, which JavaScript parses as a block. Repro: `func main() { _ = map[any]int{1: 1} }` on `js` → got `SyntaxError: Unexpected token ':'` when the output loads, want it to run. (checker-strictness Phase 6, Out of Scope)
