- **JS `switch` on map:** a nil map tag does not match `case nil` on JS. Repro: `var m map[string]int; switch m { case nil: fmt.Println("m nil") }` → js/both print nothing, want `m nil` (wasm correct). (feat/follow-ups-2026-11-10-phase-1, follow-ups-2026-11-10 Phase 1, Out of Scope)
- **Typechecker constraints:** embedding `comparable` in an interface is rejected. Repro: `type NM interface{ ~int; comparable }; func h[T NM](x T) T { return x }` → got `cannot embed non-interface type comparable`, want it to compile. (feat/follow-ups-2026-11-10-phase-1, follow-ups-2026-11-10 Phase 1, Out of Scope)
- **Interface conversion from `any`:** explicit conversion of an `any` variable to an interface with methods is accepted without a type assertion. Repro: `type I interface{ M() }; func main() { var a any; _ = I(a) }` → compiles on every target, want `need type assertion`. (#174, follow-ups-2026-11-10 Phase 2, Out of Scope)
- **JS stacked labels on range-over-func:** `continue` to the outer of two stacked labels on a range-over-func loop emits invalid JS. Repro: `func seq(y func(int) bool) { y(1) }; func main() { L1: L2: for x := range seq { _ = x; continue L1 } }` → `SyntaxError: Illegal continue statement: 'L1' does not denote an iteration statement`, want it to compile and run. (#174, follow-ups-2026-11-10 Phase 2, Out of Scope)
- **Typechecker method sets:** a struct value that embeds a pointer does not implement an interface through the pointer's methods. Repro: `type Mer interface{ M() }; type Inner struct{}; func (i *Inner) M() {}; type PO struct{ *Inner }; var w Mer = PO{&Inner{}}` → got `PO does not implement Mer` on every target, want it to compile. (feat/follow-ups-2026-11-10-phase-3, follow-ups-2026-11-10 Phase 3, Out of Scope)
- **JS promoted method sets:** a pointer method promoted through an embedded pointer two levels down is treated as outside the outer struct value's method set on JS. Repro: `type Inner struct{}; func (i *Inner) M() { fmt.Println("inner") }; type PO struct{ *Inner }; type PO2 struct{ PO }; var v any = PO2{PO{&Inner{}}}; m, ok := v.(Mer); fmt.Println(ok); m.M()` → js/both `false` then nil dereference panic, want `true\ninner` (wasm correct). (feat/follow-ups-2026-11-10-phase-3, follow-ups-2026-11-10 Phase 3, Out of Scope)
- **Ambiguous promoted methods:** a method declared by two embedded types at the same depth stays in the method set on both backends. Repro: `type Mer interface{ M() }; type A struct{}; func (A) M() {}; type B struct{}; func (B) M() {}; type C struct{ A; B }; func main() { var v any = C{}; _, ok := v.(Mer); println(ok) }` → got `true` (dispatches `A.M`), want `false`. (#175, follow-ups-2026-11-10 Phase 3, Out of Scope)
- **WASM typed-nil outer pointer:** an interface call on a nil `*PO` in `any`, whose embedded `*Inner` declares the method, panics with the wrong message. Repro: `type Mer interface{ M() }; type Inner struct{}; func (i *Inner) M() {}; type PO struct{ *Inner }; func main() { var v any = (*PO)(nil); v.(Mer).M() }` → got `interface conversion: nil or unmatched type for method call`, want `invalid memory address or nil pointer dereference`. (#175, follow-ups-2026-11-10 Phase 3, Out of Scope)
- **WASM string range into `int32` index:** ranging a string into an `int32` index variable builds an invalid module. Repro: `func main() { var i int32; for i = range "abc" { _ = i } }` → `WebAssembly.validate` fails (`local.tee[0] expected type i32, found i64.extend_i32_s`), want it to compile and run. (#175, follow-ups-2026-11-10 Phase 3, Out of Scope)
