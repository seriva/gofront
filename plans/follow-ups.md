# Follow-ups

Bugs noticed outside the task at hand, each with a repro so it can be re-checked later. Written by `/dev-loop` reviewers and by any agent session. Open items only: `/design-plan follow-ups` re-probes them and moves each into a plan (as a fix task or a deferred row), deleting it here.

- **Parser:** an unnamed generic-instance parameter type inside a func type is rejected. Repro: `func call(f func(Stack[int]) int, s Stack[int]) int { return f(s) }` → got `Parse error: Expected type, got ')'`, want compiles. (PR #78, follow-up-fixes Phase 1, Out of Scope)
- **Typechecker:** a closure with named results and a bare `return` is rejected. Repro: `g := func() (xs []int) { xs = []int{1}; return }` → got `Type error: Missing return value`, want compiles. (PR #78, follow-up-fixes Phase 1, Out of Scope)
- **Generics:** WASM rejects promotion through an embedded generic instance of a method (`Get`) and of a field via a pointer embed (`*Inner[T]`). Repro: `type Inner[T any] struct{v T}; func (i Inner[T]) Get() T {return i.v}; type W[T any] struct{Inner[T]}; W[int]{}.Get()` in a `wasm` package → got `Unknown field 'Get' on struct 'W$int'`, want it compiles; `type P[T any] struct{*Inner[T]}; p.v` → got `No field 'v' on P$string`, want field promoted. (feat/follow-up-fixes-phase-2, follow-up-fixes Phase 2, Out of Scope)
- **WASM type switch:** a type switch with `case nil` plus an interface case fails to compile (pre-existing). Repro: `var err error; switch err.(type) { case nil: fmt.Println("nil"); case error: fmt.Println("e") }` → got `iface.methods is not iterable` on WASM, want `nil`. (PR #79, follow-up-fixes Phase 2, Out of Scope)
- **Parser:** a trailing-dot float literal is mis-lexed. Repro: `z := 1.; fmt.Println(z)` → got WASM `Cannot resolve struct for selector: ;`, want `1`. (PR #79, follow-up-fixes Phase 2, Out of Scope)
- **WASM codegen:** deref of `new([]int)` fails validation. Repro: `xs := new([]int); fmt.Println(len(*xs))` → got WASM validation failure `not enough arguments on the stack for i64.extend_i32_u`, want `0`. (PR #79, follow-up-fixes Phase 2, Out of Scope)
- **Parser:** an array type as a generic type argument in a composite literal is rejected. Repro: `s := Stack[[2]int]{}` → got `Parse error: expected '{' (got ])`, want compiles. (PR #79, follow-up-fixes Phase 2, Out of Scope)
- **Lexer:** an imaginary literal with no leading digit is mis-lexed. Repro: `c := .5i` → got `Undefined: 'i'`, want `(0+0.5i)`. (PR #79, follow-up-fixes Phase 2, Low)
- **Embedded generics:** a method of an embedded generic instance is not promoted through a non-generic wrapper. Repro: `type Inner[T any] struct{V T}; func (i Inner[T]) Get() T { return i.V }; type W struct{ Inner[int] }; W{}.Get()` → got `No field 'Get' on W` (js, wasm, both), want `0`. (PR #79, follow-up-fixes Phase 2, Out of Scope)
- **WASM facade:** an exported struct with a `strings.Builder` (or `*strings.Reader`) field makes the JS facade emit an invalid identifier. Repro: `type S struct{ sb strings.Builder }` in a `wasm` package → got `SyntaxError: Missing initializer in const declaration` (`const __gfw_h_strings.Builder = ...`), want compiles (unexported type works). (branch feat/follow-up-fixes-phase-3, follow-up-fixes Phase 3, Out of Scope)
- **Defined struct types:** a defined type over a generic instance or an alias of a struct loses its fields in JS. Repro: `type Base[T any] struct{n T}; type S Base[int]; func (s S) N() int { return s.n }; s := S{n: 3}; fmt.Println(s.n, s)` (same with `type A = Base; type T A`) → got js/both `<nil> 3`, want `3 {3}` (WASM correct); without a method on the alias form JS fails with `T is not defined`. (PR #80, follow-up-fixes Phase 3, Low)
- **Defined struct types:** a defined struct type used as a map key prints without its zero `<nil>` field in JS. Repro: `type Base struct{p *int; n int}; type K Base; m := map[K]int{}; m[K{nil, 1}] = 2; fmt.Println(m)` → got js/both `map[{ 1}:2]`, want `map[{<nil> 1}:2]` (WASM correct). (PR #80, follow-up-fixes Phase 3, Low)
- **Typechecker:** pointer conversion between struct types with identical fields is rejected. Repro: `type Base struct{n int}; type S Base; b := Base{1}; p := (*S)(&b)` → got `Cannot call non-function type *S`, want compiles. (PR #80, follow-up-fixes Phase 3, Out of Scope)
- **Packages:** two imported packages that declare the same type name collide in generated output, and typeStr-based identity treats them as equal. Repro: `a.Pt{X int}` and `b.Pt{Y string}` both used from `main` (js) → got `Identifier 'Pt' has already been declared` (wasm: `'Pt' is declared in both 'a' and 'b'`); `var x Box[a.Pt]; x = Box[b.Pt]{}` → got compiles, want `cannot use`. Also `Box[a.Pt]` and `Box[b.Pt]` in one project typecheck but `node out.js` fails `Identifier 'Pt' has already been declared`. (PR #81, feat/follow-up-fixes-phase-4, follow-up-fixes Phase 4, Out of Scope)
- **Typechecker:** `int` and `float64` values are implicitly interchangeable outside generic call results. Repro: `var y float64 = 1; var i int = y` → got compiles, want `cannot use y (variable of type float64) as int value`. (feat/follow-up-fixes-phase-4, follow-up-fixes Phase 4, Out of Scope)
- **Generics:** a generic method whose signature instantiates its own type with a larger argument crashes the compiler even when never called. Repro: `type Stack[T any] struct{ items []T }; func (s Stack[T]) Wrap() Stack[[]T] { return Stack[[]T]{} }` (also `Wrap2() Stack[Stack[T]]`) → got `Maximum call stack size exceeded` on js, both, wasm (same on base), want compiles. Method body `x := Stack[[]T]{}` → wasm `Monomorphisation exceeded maximum iteration limit`, js/both `0`. (PR #81, follow-up-fixes Phase 4, Out of Scope)
- **Aliases (JS):** an alias of a struct breaks positional literals, methods, copies and embedding in js/both. Repro: `type Base struct{V int}; func (b Base) Get() int { return b.V }; type A = Base; A{3}` → got `A is not defined`; `A{V:3}.Get()` → `s.Get is not a function`; `var t Base = A{V:1}` → `s.__clone is not a function`; `type W struct{A}; w.V` → `Cannot read properties of undefined`; want all to work (wasm does). (PR #81, follow-up-fixes Phase 4, Out of Scope)
- **WASM:** `_ = *p` on a nil struct pointer traps with V8's `dereferencing a null pointer` instead of a Go panic that `recover()` can catch. Repro: `defer func(){ fmt.Println(recover()) }(); var p *struct{A int}; _ = *p` (wasm) → got uncaught trap, want `runtime error: invalid memory address or nil pointer dereference`. (feat/follow-up-fixes-phase-5, follow-up-fixes Phase 5, Out of Scope)
- **JS else-if init:** the init statement of an `else if` is dropped. Repro: `a := 1; b := 5; if a > 5 {} else if b := b+1; b > 5 { println("elif") } else { println("else") }` → got js/both `else` (and `b is not defined` when `b` is new), want `elif`; wasm correct. (PR #82, follow-up-fixes Phase 5, Out of Scope)
- **JS shadowing TDZ:** `x := f(x)` still hits the temporal dead zone in switch case bodies, `for n := n; ...` and comma-ok forms. Repro: `m := map[int]int{1:7}; k := 1; { k, ok := m[k]; fmt.Println(k, ok) }` → got js/both `Cannot access 'k' before initialization`, want `7 true`. (PR #82, follow-up-fixes Phase 5, Out of Scope)
- **JS nil receivers:** a nil-checking pointer method still throws when reached through an interface, method value, method expression, a nil embedded pointer, or from another package. Repro: `var nl *L; var li Lener = nl; li.Len()` (`func (l *L) Len() int { if l == nil { return 0 }; ... }`) → got `Cannot read properties of null (reading 'Len')`, want `0`. (PR #82, follow-up-fixes Phase 5, Out of Scope)
- **JS nil field access:** `p.A` on a nil struct pointer gives a TypeError text in the `js` target. Repro: `var p *S; defer func(){ fmt.Println(recover()) }(); _ = p.A` → got `Cannot read properties of null (reading 'A')`, want `runtime error: invalid memory address or nil pointer dereference` (`both` and `wasm` are right). (PR #82, follow-up-fixes Phase 5, Low)
- **WASM shadowing:** `m := f(m)` inside a func literal that captures the outer `m` fails. Repro: `m := 7; func(){ m := f(m); m++ }()` → got `Unresolved identifier: m`, want compiles. (PR #82, follow-up-fixes Phase 5, Out of Scope)
- **WASM blank var:** `var _, y = two()` in a function body fails validation. Repro: `func f() int { var _, y = two(); return y }` → got `local.set expected i32, found call i64`, want `2`. (PR #82, follow-up-fixes Phase 5, Out of Scope)
- **Typechecker nil conversions:** conversions of `nil` to pointer, named and func types are rejected. Repro: `var _ I = (*T)(nil)` → got `Cannot call non-function type *T`; `NS(nil)`, `F(nil)`, `(*int)(nil)` → `cannot convert nil to ...`; want all to compile. (PR #82, follow-up-fixes Phase 5, Out of Scope)
- **JS nil values:** nil conversions and prints are wrong. Repro: `fmt.Println(error(nil) == nil)` → got js `false`, want `true`; `map[string]int(nil)` → `Cannot convert undefined or null to object`, want an empty nil map; `fmt.Println(make([][]int, 2))` → `[<nil> <nil>]`, want `[[] []]`. (PR #82, follow-up-fixes Phase 5, Out of Scope)
