- **JS type switch:** a `case func():` (or any func-type case) on an `any` always matches in JS because the check is emitted as `if (true)`, so non-func values and funcs of other signatures take that case. Repro: `switch x.(type) { case func(): return "f"; default: return "d" }` with `kind(1)` and `kind(func(int) string {...})` → got `f f` on js/both, want `d d` (wasm prints `d`). (feat/follow-ups-2026-11-03-phase-1, follow-ups-2026-11-03 Phase 1, Out of Scope)
- **WASM pointer conversion:** `(*S)(&b)` between two struct types with identical fields (`type S Base`) is rejected in wasm and both packages because WebAssembly struct types are nominal and the two pointers cannot share one object. Repro: `type Base struct{n int}; type S Base; b := Base{1}; p := (*S)(&b)` in a `//gofront:target both` package → got `cannot convert *Base to *S in a wasm package`, want compiles and `p.n` aliases `b.n`. (feat/follow-ups-2026-11-03-phase-2, follow-ups-2026-11-03 Phase 2, Out of Scope)
- **JS pointer conversion:** a method called through a pointer converted to another struct type fails because the object keeps the source type's class. Repro: `type Base struct{n int}; type S Base; func (s *S) Inc() { s.n++ }; b := Base{1}; (*S)(&b).Inc()` → got `p.Inc is not a function`, want `b.n == 2`. (feat/follow-ups-2026-11-03-phase-2, follow-ups-2026-11-03 Phase 2, Out of Scope)
- **JS comma-ok define boxing:** an address-taken variable bound by a comma-ok map read is never boxed, so writing through the pointer throws. Repro: `m := map[string]int{"k": 3}; x, y := m["k"]; p := &x; *p = 9; println(x, y)` → got `Cannot create property 'value' on number '3'`, want `9 true`. (feat/follow-ups-2026-11-03-phase-2, follow-ups-2026-11-03 Phase 2, Out of Scope)
- **Switch on constant tag:** a `switch` on an untyped constant string tag with an untyped int case is not rejected and emits invalid WASM. Repro: `package main; func main() { switch "foo" { case 5: } }` compiled for `wasm` → got `WebAssembly.Module(): Compiling function … call[1] expected type externref, found i64.const`, want type error `cannot convert 5 (untyped int constant) to type string`. (feat/follow-ups-2026-11-03-phase-3, follow-ups-2026-11-03 Phase 3, Out of Scope)
- **Untyped float to int:** an untyped float constant with a fractional part is accepted for an `int` variable. Repro: `package main; func main() { var i int = 1.5; _ = i }` → got no error, want `cannot use 1.5 (untyped float constant) as int value in variable declaration (truncated)`. (feat/follow-ups-2026-11-03-phase-3, follow-ups-2026-11-03 Phase 3, Out of Scope)
- **WASM nil embedded pointer method call:** calling a value-receiver method through a nil embedded struct pointer traps uncatchably instead of a recoverable nil-dereference panic. Repro: `type Base struct{ v int }; func (b Base) Val() int { return b.v }; type P struct{ *Base }; func main() { defer func() { if recover() != nil { fmt.Println("recovered") } }(); fmt.Println(P{}.Val()) }` → got `RuntimeError: dereferencing a null pointer`, want `recovered`. (PR #111, follow-ups-2026-11-03 Phase 4, Out of Scope)
- **Package type vs main type:** a `main` type with the same name as a type in an imported package makes `pkg.T{...}` resolve to the main type. Repro: `package a; type Pt struct{ X int }` and `package main; type Pt struct{ Z bool }; func main() { fmt.Println(Pt{true}, a.Pt{1}) }` → got `Cannot assign untyped int to bool`, want `{true} {1}`. (feat/follow-ups-2026-11-03-phase-5, follow-ups-2026-11-03 Phase 5, Out of Scope)
- **JS `%T` of generic instances in `any` and generic bodies:** `%T` of a generic instance stored in an `any`, or built from a type parameter inside a generic function, prints the bare class name on js/both. Repro: `var a any = Box[int]{}; fmt.Printf("%T\n", a)` and `func show[T any](v T) { fmt.Printf("%T\n", Box[T]{}) }; show(2.5)` → got `main.Box` and `main.Box[interface {}]`, want `main.Box[int]` and `main.Box[float64]`. (feat/follow-ups-2026-11-03-phase-5, follow-ups-2026-11-03 Phase 5, Out of Scope)
- **Cross-package struct alias literal in JS:** an alias of a struct exported from another package cannot be instantiated from `main`. Repro: `package p; type Base struct{ V int }; type A = Base` and `main` evaluating `p.A{42}` on js → got `ReferenceError: A is not defined`, want `{42}`. (feat/follow-ups-2026-11-03-phase-5, follow-ups-2026-11-03 Phase 5, Out of Scope)
- **JS labeled loop with hoisted init:** stacked labels on a `for` whose init shadows an outer name leave the outer label on the hoisting block, so `continue outer` is illegal in JS. Repro: `n := 1; outer: inner: for n := n + 1; n < 3; n++ { continue outer }` on js → got `Illegal continue statement: 'outer' does not denote an iteration statement`, want the loop to continue. (PR #113, follow-ups-2026-11-03 Phase 6, Low)
- **Comma-ok type assertion with no new variables:** `x, ok := a.(int)` is accepted when both `x` and `ok` are already declared in the scope. Repro: `var a any = 1; var x int; var ok bool; x, ok = nil, false; x, ok := a.(int)` → got no error, want `no new variables on left side of :=`. (PR #113, follow-ups-2026-11-03 Phase 6, Out of Scope)
- **Nil map operations on js:** `delete(m, k)` on a nil map throws; comma-ok read and `range` on a nil map also throw. Repro: `m := map[string]int(nil); delete(m, "a")` on js → got `Cannot convert undefined or null to object`, want no-op. (PR #114, follow-ups-2026-11-03 Phase 7, Out of Scope)
- **Nil map printing on js:** `fmt.Println` of a nil map prints `<nil>`. Repro: `var m map[string]int; fmt.Println(m)` on js → got `<nil>`, want `map[]`. (PR #114, follow-ups-2026-11-03 Phase 7, Out of Scope)
- **Method values and expressions on nil generic pointers:** `(*Box[int]).M` applied to a nil pointer throws. Repro: `type Box[T any] struct{ v T }; func (b *Box[T]) M() int { return 0 }; var b *Box[int]; g := (*Box[int]).M; g(b)` on js → got `Cannot read properties of null (reading 'M')`, want `0`. (PR #114, follow-ups-2026-11-03 Phase 7, Out of Scope)
- **Method value on nil pointer without a nil check:** binding a method value on a nil pointer throws. Repro: `type S struct{}; func (s *S) Ping() { fmt.Println("ping") }; var s *S; f := s.Ping; f()` on js → got `Cannot read properties of null (reading 'Ping')`, want `ping`. (PR #114, follow-ups-2026-11-03 Phase 7, Out of Scope)
- **WASM complex struct field:** a struct with a `complex128` field fails WASM validation. Repro: `type P struct{ Z complex128 }; fmt.Println(P{Z: complex(4, 1)})` on wasm → got `struct.set: Field 0 of type 9 is immutable`, want `{(4+1i)}`. (feat/follow-ups-2026-11-03-phase-8, follow-ups-2026-11-03 Phase 8, Out of Scope)
- **Typed nil pointers in `any` on js:** two interface values holding nil non-struct pointers of the same type compare unequal. Repro: `var p1, p2 *int; var a1, a2 any = p1, p2; fmt.Println(a1 == a2)` on js → got `false`, want `true`. (PR #116, follow-ups-2026-11-03 Phase 9, Low)
- **Nil slice in `any` on js:** a type assertion to the slice type fails on a nil slice, and a nil slice or func in `any` still equals nil. Repro: `var s []int; var a any = s; _, ok := a.([]int); fmt.Println(ok, a == nil)` on js → got `false true`, want `true false`. (PR #116, follow-ups-2026-11-03 Phase 9, Low)
- **Nil checks and boxing inside generic functions on js:** `any(v) == nil` is wrong for nil pointers and slices, and a type switch on `any(v)` of a named string type parameter value matches `case string` before `case T`. Repro: `func F[T any](v T) bool { return any(v) == nil }; var p *int; fmt.Println(F(p))` on js → got `true`, want `false`. (PR #116, follow-ups-2026-11-03 Phase 9, Out of Scope)
- **Pointer-receiver method on a type parameter on js:** calling a pointer-receiver constraint method on a type parameter value throws. Repro: `type Counter int; func (c *Counter) Inc() { *c++ }; type Incer interface{ Inc() }; func Step[T Incer](x T) { x.Inc() }; c := Counter(5); Step(&c)` on js → got `__tbox(...).Inc is not a function`, want `c == 6`. (PR #116, follow-ups-2026-11-03 Phase 9, Out of Scope)
- **Promoted pointer-receiver method in interface assertions on js:** an embedded struct value's pointer-receiver method counts toward the outer value's method set. Repro: `type Inner struct{}; func (i *Inner) M() {}; type Outer struct{ Inner }; type Mer interface{ M() }; var v any = Outer{}; _, ok := v.(Mer); fmt.Println(ok)` on js → got `true`, want `false`. (PR #116, follow-ups-2026-11-03 Phase 9, Out of Scope)
- **JSON-decoded `any` in type switches on js:** values decoded into `any` are untagged, so they match any element type. Repro: `var d any; json.Unmarshal([]byte("[1, 2]"), &d); switch d.(type) { case []string: fmt.Println("match") }` on js → got `match`, want no match. (PR #116, follow-ups-2026-11-03 Phase 9, Out of Scope)
- **Array map keys on wasm alias the caller's array:** mutating an array after using it as a map key changes the stored key. Repro: `ar := map[[2]int]int{}; key := [2]int{1,2}; ar[key] = 5; key[0] = 9; fmt.Println(ar[[2]int{1,2}], len(ar))` on wasm → got `0 1`, want `5 1`; also `for k := range ar { k[0]++ }` changes the stored key. (feat/follow-ups-2026-11-03-phase-10, follow-ups-2026-11-03 Phase 10, Out of Scope) (PR #117 review)
- **Unhashable key held in `any` on js:** a slice stored in an `any` variable used as a `map[any]` key does not panic. Repro: `var x any = []int{1}; m := map[any]int{}; m[x] = 1` on js → got no panic, want `runtime error: hash of unhashable type []int`. (PR #117, follow-ups-2026-11-03 Phase 10, Out of Scope)
- **Nil map `%p` on js:** a nil map prints a non-zero id. Repro: `var m map[string]int; fmt.Println(fmt.Sprintf("%p", m))` on js → got `0x1`, want `0x0`. (PR #118, follow-ups-2026-11-03 Phase 11, Out of Scope)
- **`%+v` width on composites:** the `+` flag pads the whole composite instead of each element. Repro: `fmt.Sprintf("%+5v", []int{1})` → got `   [1]`, want `[    1]`. (PR #118, follow-ups-2026-11-03 Phase 11, Out of Scope)
- **`%s` of a nil `*T` without `String`:** prints `<nil>`. Repro: `type T struct{}; var p *T; fmt.Sprintf("%s", p)` → got `<nil>`, want `%!s(*main.T=<nil>)`. (PR #118, follow-ups-2026-11-03 Phase 11, Out of Scope)
- **fmt typed values in `any` variables:** only `any(x)` operands keep their static type for `%T`/`%v`; a value stored in an `any` variable loses it. Repro: `var x any = float32(0.1); fmt.Println(x)` → got `0.10000000149011612` (js/both/wasm), want `0.1`; `var u any = uint64(1); fmt.Printf("%T", u)` → got `int64` (js) / `int` (wasm), want `uint64`; `var p *Color; var a any = p; fmt.Printf("%T", a)` → wasm got `<nil>`, want `*main.Color` (js is correct). (feat/follow-ups-2026-11-03-phase-12, follow-ups-2026-11-03 Phase 12, Out of Scope)
- **fmt nil Stringer pointers in `any` on WASM:** a nil pointer with a pointer-receiver `String` stored in `any`/`[]any` prints `<nil>`. Repro: `var cp *C; var x any = cp; fmt.Sprint(x, []any{cp})` → wasm got `<nil> [<nil>]`, want `c [c]` (js is correct). (feat/follow-ups-2026-11-03-phase-12, follow-ups-2026-11-03 Phase 12, Out of Scope; same cause as Phase 13 Task 13.3)
