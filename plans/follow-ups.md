- **Typechecker conversions:** Calling an alias of an anonymous struct type as a conversion is rejected. Repro: `type A = struct{ X int }; type S struct{ X int }; u := A(S{1})` → got `Cannot call non-function type struct{...}`, want a converted value. (feat/follow-ups-2026-11-16-phase-1, follow-ups-2026-11-16 Phase 1, Out of Scope)
- **Parser:** A struct type with a field tag inside generic type arguments does not parse. Repro: `type Box[T any] struct{ V T }; var c Box[struct{ X int `json:"x"` }]` → got `Parse error at 3:10: Expected top-level declaration (got [ "[")`, want it to compile. (feat/follow-ups-2026-11-16-phase-1, follow-ups-2026-11-16 Phase 1, Out of Scope)
- **Typechecker generics:** Grouped and ungrouped field declarations of the same anonymous struct get separate generic instances. Repro: `type Box[T any] struct{ V T }; a := Box[struct{ X, Y int }]{}; b := Box[struct{ X int; Y int }]{}; fmt.Printf("%T %T\n", a, b)` → got `main.Box[struct { X, Y int }] main.Box[struct { X int; Y int }]`, want identical types. (feat/follow-ups-2026-11-16-phase-1, follow-ups-2026-11-16 Phase 1, Low)
- **Parser:** A parenthesised anonymous struct type conversion does not parse. Repro: `type S struct{ A [2]int }; s := S{}; u := (struct{ A [2]int })(s)` → got `Parse error at 7:26: expected '{' (got ) ")")`, want a converted value. (feat/follow-ups-2026-11-16-phase-1, follow-ups-2026-11-16 Phase 1, Out of Scope)
- **Local types:** A function-local type named after an imported package takes over the import in other functions. Repro: `import ("fmt"; "strings"); func other() int { type strings = int; var x strings = 3; return x }; func main() { fmt.Println(other(), strings.ToUpper("ab")) }` → got `int has no field or method 'ToUpper'`, want `3 AB`. (feat/follow-ups-2026-11-16-phase-1, follow-ups-2026-11-16 Phase 1, Out of Scope)
- **Typechecker generics:** Generic instances over func or interface types that mention different anonymous structs collide. Repro: `type Box[T any] struct{ V T }; a := Box[func(struct{ X int })]{V: func(s struct{ X int }) { fmt.Println(s.X) }}; var b Box[func(struct{ S string })] = a; b.V(struct{ S string }{"hi"})` → got `-9223372036854775808`, want a compile error. (feat/follow-ups-2026-11-16-phase-1, follow-ups-2026-11-16 Phase 1, Out of Scope)
- **JS value semantics:** Copying a plain embedded anonymous struct shares the embedded struct's storage. Repro: `type P struct{ N int }; v := struct{ P }{P{3}}; w := v; w.P.N = 8; fmt.Println(v.N)` → got `8`, want `3`. (feat/follow-ups-2026-11-16-phase-1, follow-ups-2026-11-16 Phase 1, Out of Scope)
- **Untyped npm imports:** An unused or `.`-aliased untyped npm import in a `wasm`/`both` package compiles silently, while `import _` is rejected. Repro: `//gofront:target wasm` + `import "nope/zzz"; func main() { println("ok") }` → got compiles, want `'zzz' imported and not used` or `js: imports are not allowed in wasm packages`. (PR #210, follow-ups-2026-11-16 Phase 2, Low)
- **Untyped npm imports:** A qualified type from an untyped import in a `wasm` package reports `Unknown type` instead of the JS-only error. Repro: `//gofront:target wasm` + `import "nope/zzz"; func main() { var x zzz.T; _ = x }` → got `Unknown type 'zzz.T'`, want `'zzz' is only available in js packages`. (PR #210, follow-ups-2026-11-16 Phase 2, Low)
- **Package exports:** Uppercase imported globals leak through `getExportedSymbols` as members of a sub-package. Repro: `sub/sub.go` `package sub; import "mydep"; func Use() any { return Bar }` with `export declare const Bar: number;` in `mydep`, main `println(sub.Bar)` → got compiles and emits `console.log(Bar)`, want compile error (`sub` has no `Bar`). (PR #210, follow-ups-2026-11-16 Phase 2, Out of Scope)
- **WASM emitter:** A composite literal of a qualified name on a non-package global crashes the emitter. Repro: `//gofront:target wasm` + `func main() { _ = console.T{} }` → got `Error: Unknown struct in CompositeLit: any`, want a type error. (PR #210, follow-ups-2026-11-16 Phase 2, Out of Scope)
- **Imports:** npm import bindings are package-wide, not per file. Repro: `a.go` `import "nope/zzz"; func f() { zzz.F() }`, `b.go` `func main() { zzz.G() }` → got compiles, want `Undefined: 'zzz'` in `b.go`. (PR #210, follow-ups-2026-11-16 Phase 2, Out of Scope)
