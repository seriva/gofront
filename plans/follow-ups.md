- **Typechecker switch:** An untyped bool constant tag skips case checking because of the `tagType.base !== "bool"` guard in `statements.js`. Repro: `switch true { case 5: }` → got compiles, want `cannot convert 5 (untyped int constant) to type bool`. (PR #154, follow-ups-2026-11-07 Phase 1, Out of Scope)
- **Typechecker switch:** A tagless `switch` accepts `case nil:`. Repro: `switch { case nil: }` → got compiles, want `cannot convert nil to type bool`. (PR #154, follow-ups-2026-11-07 Phase 1, Out of Scope)
- **Typechecker builtins:** `cap` accepts integer and bool arguments. Repro: `_ = cap(1)` → got compiles, want `invalid argument: 1 (untyped int constant) for cap`. (PR #154, follow-ups-2026-11-07 Phase 1, Out of Scope)
- **Typechecker package types:** A function-local type sharing a name with an imported package type mutates the imported type in place, breaking later `pkg.T{...}`. Repro: `package a; type Pt struct{X int}` + `main`: `func main() { type Pt struct{Z bool}; _ = a.Pt{1} }` → got `Cannot assign untyped int to bool`, want compiles. (PR #155, follow-ups-2026-11-07 Phase 2, Out of Scope)
- **Typechecker array lengths:** Negative constant array lengths via package or local constants are not rejected. Repro: `var a [math.MinInt8]int` → got no errors, want `invalid array length -128 (must be non-negative)`. (PR #155, follow-ups-2026-11-07 Phase 2, Out of Scope)
- **JS local shadowing:** A variable named like a function-local type in the same function hits a TDZ error. Repro: `func a() { type Dup struct{X int}; Dup := 1; fmt.Println(Dup) }` → got `ReferenceError: Cannot access 'Dup' before initialization`, want `1`. (PR #155, follow-ups-2026-11-07 Phase 2, Out of Scope)
- **JS 64-bit constants:** a package-level untyped integer constant used directly as an operand of a `uint64`/`int64` compound assignment is emitted as a Number next to a BigInt. Repro: `const half = 1 << 51; var b uint64 = 1; b += half; fmt.Println(b)` on `both` → got `TypeError: Cannot mix BigInt and other types`, want `2251799813685249`. (feat/follow-ups-2026-11-07-phase-3, follow-ups-2026-11-07 Phase 3, Out of Scope)
- **JS labeled iterator range:** A labeled range-over-func loop emits `continue outer` against a block. Repro: `func seq(yield func(int) bool) { yield(0) }; outer: for x := range seq { break outer }` on `js` → got `SyntaxError: Illegal continue statement`, want compiles and breaks. (PR #156, follow-ups-2026-11-07 Phase 3, Out of Scope)
- **JS map range into address-taken var:** `for _, v = range m` destructures onto the box instead of `v.value`. Repro: `m := map[string]int{"a": 1}; var v int; p := &v; for _, v = range m {}; fmt.Println(*p)` on `js` → got `0`, want `1`. (PR #156, follow-ups-2026-11-07 Phase 3, Out of Scope)
- **WASM unhashable func key:** The panic for a func stored in an `any` map key omits the type name. Repro: `defer func() { fmt.Println(recover()) }(); var f any = func() {}; m := map[any]int{}; m[f] = 1` on `wasm` → got `runtime error: hash of unhashable type`, want `runtime error: hash of unhashable type func()`. (feat/follow-ups-2026-11-07-phase-4, follow-ups-2026-11-07 Phase 4, Out of Scope)
- **JS nil pointer method call:** A direct pointer-receiver call on a nil pointer throws on JS. Repro: `type S struct{}; func (s *S) Ping() {}; var s *S; s.Ping()` → got `TypeError: Cannot read properties of null (reading 'Ping')`, want runs without error. (PR #157, follow-ups-2026-11-07 Phase 4, Out of Scope)
- **JS nil non-struct pointer method value:** Method expressions on a nil pointer to a named non-struct type throw on JS. Repro: `type MyInt int; func (m *MyInt) Ping() int { return 1 }; var p *MyInt; g := (*MyInt).Ping; g(p)` → got `TypeError`, want `1`. (PR #157, follow-ups-2026-11-07 Phase 4, Out of Scope)
- **JS unhashable `any` keys:** A struct containing a slice, or a defined slice type, in `any` used as a `map[any]` key does not panic on JS. Repro: `type S struct{ s []int }; var x any = S{[]int{1}}; m := map[any]int{}; m[x] = 1` → got no panic, want `runtime error: hash of unhashable type main.S`. (PR #157, follow-ups-2026-11-07 Phase 4, Out of Scope)
- **WASM embedded pointer promoted methods in `any`:** A struct value embedding `*Inner` does not satisfy an interface asserted from `any` on WASM. Repro: `type Mer interface{ M() }; type Inner struct{}; func (*Inner) M() {}; type PO struct{ *Inner }; var v any = PO{}; _, ok := v.(Mer); fmt.Println(ok)` → got `false` on wasm, want `true`. (feat/follow-ups-2026-11-07-phase-5, follow-ups-2026-11-07 Phase 5, Out of Scope)
- **WASM stdlib interface assertion on slice types:** A named slice from the Go-source stdlib is not matched by its interface in `any` on WASM. Repro: `var v any = sort.IntSlice{1}; _, ok := v.(sort.Interface); fmt.Println(ok)` → got `false` on wasm, want `true`. (feat/follow-ups-2026-11-07-phase-5, follow-ups-2026-11-07 Phase 5, Out of Scope)
- **JS defined func types and nil defined slices in `any`:** A defined func type is not told apart from its unnamed form, and a nil defined slice loses its type, in `any` on JS; tagging mutates the shared func object. Repro: `type G func(string) string; var a any = func(s string) string { return s }; _, ok := a.(G); type S []int; var b any = S(nil); _, ok2 := b.(S); fmt.Println(ok, ok2)` → got `true false` on js/both, want `false true`. (feat/follow-ups-2026-11-07-phase-5, follow-ups-2026-11-07 Phase 5, Out of Scope)
- **Parser constraint element lists:** An interface with a type-set element in a method-bearing constraint fails to parse. Repro: `type Incer[T any] interface{ *T; Inc() }` → got `Parse error: expected 'IDENT' (got * "*")`, want compiles. (feat/follow-ups-2026-11-07-phase-5, follow-ups-2026-11-07 Phase 5, Out of Scope)
- **JS nil embedded pointer with pointer-receiver method:** Calling a pointer-receiver method promoted through a nil embedded pointer throws a `TypeError` on JS, where Go calls the method with a nil receiver. Repro: `type Base struct{}; func (b *Base) Ptr() int { return 1 }; type P struct{ *Base }; fmt.Println(P{}.Ptr())` → got `TypeError: Cannot read properties of null (reading 'Ptr')` on js, want `1`. (feat/follow-ups-2026-11-07-phase-6, follow-ups-2026-11-07 Phase 6, Out of Scope)
