# Follow-ups

Bugs noticed outside the task at hand, each with a repro so it can be re-checked later. Written by `/dev-loop` reviewers and by any agent session. Open items only: `/design-plan follow-ups` re-probes them, groups them by root cause, and moves each into a plan (as a fix task or a deferred row), deleting it here.

Each entry names its root cause (the mechanism that produces it, not the path that exposed it) and its route: the open plan whose scope covers that root, or `unrouted`. Entries with the same root sit together. A defect with the same root as the task being fixed is part of that task and never lands here (`/dev-loop` **Follow-ups**).

- **JS discarded map literal:** a discarded map literal with computed keys is emitted as a statement starting with `{`. Root: `js-stmt-expr-start` (expression statements are not parenthesised when they begin with `{`). Repro: `func main() { _ = map[any]int{1: 1} }` on `js` → got `SyntaxError: Unexpected token ':'`, want it to run. (checker-strictness Phase 6, Out of Scope; re-probed 2026-11-17) → unrouted
- **Complex constants:** untyped complex constants are not tracked by value, so an integral one is rejected against a real type. Root: `complex-const-eval` (`src/typechecker/constants.js:CONST_KINDS` and `const-fold.js` have no complex constant). Repro: `var f float64 = 1; _ = f + (1 + 0i)` → got `overflows float64`, want accepted. (PR #234, checker-go-rules Phase 1, Out of Scope) → unrouted
- **float32 constants:** a constant too large for float32 is accepted. Root: `float32-const-overflow` (`src/typechecker/constants.js:_checkConstOverflow` only checks integer ranges). Repro: `var f float32 = 1; _ = f == 1e40` → got accepted, want `overflows float32`. (PR #234, checker-go-rules Phase 1, Out of Scope) → unrouted
- **Interface comparison:** comparing an interface with a concrete value does not check that the type implements the interface. Root: `interface-cmp-check` (`src/typechecker/assignability.js:_checkCmpOperandTypes` returns early for non-basic left operands). Repro: `type I interface{ M() }; var i I; _ = i == 1` → got accepted, want `mismatched types I and untyped int`. (PR #234, checker-go-rules Phase 1, Out of Scope) → unrouted
- **Ordering on bool:** `<` on booleans is accepted. Root: `cmp-ordering-kind` (`src/typechecker/assignability.js:_binaryResultTypeCmp` does not check ordering kinds). Repro: `b := true; _ = b < true` → got accepted, want `operator < not defined on bool`. (PR #234, checker-go-rules Phase 1, Out of Scope) → unrouted
- **Switch on type parameter:** `case nil` on a non-nilable type parameter is accepted and ICEs on wasm. Root: `switch-case-nil-type-param` (`src/typechecker/statements.js:_caseValueUnchecked` returns true for typeParam). Repro: `func f[T any](x T) { switch x { case nil: } }; f(1)` → got ICE on wasm, want compile error. (PR #234, checker-go-rules Phase 1, Out of Scope) → unrouted
- **Logical operators:** `&&`/`||` on two non-bool operands or with `nil` are accepted. Root: `logical-operand-kind` (`src/typechecker/assignability.js:_checkLogicalOperands` only checks typed bool). Repro: `_ = 1 && 2` → got accepted, want `operator && not defined on 1`. (PR #234, checker-go-rules Phase 1, Out of Scope) → unrouted
- **Comparison errors:** comparing a non-comparable type with an incompatible constant reports two errors. Root: `cmp-double-error` (`_binaryResultTypeCmp` still calls `_checkEqualityComparable` after a mismatch). Repro: `var s []int; _ = s == 1` → got two errors, want one. (PR #234, checker-go-rules Phase 1, Low) → unrouted
- **Untyped shift operand:** an untyped float constant as shifted operand is accepted and ICEs on wasm. Root: `untyped-shift-operand` (`src/typechecker/assignability.js:_binaryResultTypeShift` skips the integer check for untyped left operands). Repro: `_ = 1.5 << 1` → got accepted (wasm ICE), want `shifted operand 1.5 (untyped float constant) must be integer`. (PR #235, checker-go-rules Phase 2, Out of Scope) → unrouted
- **Untyped shift to complex:** a non-constant untyped shift converted to a complex type is accepted. Root: `untyped-shift-complex-target` (`assignability.js:_retypeUntypedShift` ignores non-integer targets). Repro: `var c complex128 = 1i; k := uint(1); c += 1 << k` → got `(2+1i)`/wasm ICE, want `shifted operand 1 (type complex128) must be integer`. (PR #235, checker-go-rules Phase 2, Out of Scope) → unrouted
- **Complex ++/--:** `++` on a complex value miscompiles. Root: `complex-incdec-codegen` (`src/backend/js/statements.js` IncDecStmt, `src/backend/wasm/emit-stmts.js:emitIncDecStmt` treat complex as scalar). Repro: `var c complex128 = 1i; c++; fmt.Println(c)` → got `(NaN+NaNi)` (wasm ICE), want `(1+1i)`. (PR #235, checker-go-rules Phase 2, Out of Scope) → unrouted
- **IncDec on constant:** `++` on a constant is accepted. Root: `addressability` (`statements.js:_checkIncDecStmt` has no assignability check). Repro: `const k = 1; k++` → got js `InternalCompilerError`, wasm accepts, want `cannot assign to k`. (PR #235, checker-go-rules Phase 2, Out of Scope) → checker-go-rules
- **Non-strict JS int wrap:** small-int `++` and shifts do not wrap in non-strict js. Root: `js-nonstrict-int-wrap` (`src/backend/js/statements.js` IncDecStmt wraps only when `this.strict`). Repro: `var x uint8 = 255; x++` on `js` → got `256`, want `0`. (PR #235, checker-go-rules Phase 2, Out of Scope) → unrouted
- **Shift diagnostics:** `f <<= 1.5` on a float reports both the shift count and shifted operand errors. Root: `shift-double-error` (`assignability.js:_binaryResultTypeShift`). Repro: `var f float64 = 1.0; f <<= 1.5` → got two errors, want one. (PR #235, checker-go-rules Phase 2, Low) → unrouted
- **Nested assignability:** a pointer or array of a concrete type is assignable to a pointer or array of `any`. Repro: `var p *int; var q *any = p` → got accepted, want `cannot use p (variable of type *int) as *any value`. (PR #236, checker-go-rules Phase 3, Out of Scope) → unrouted
- **Pointer conversion:** converting between pointers to identical underlying empty-interface types is rejected. Root: `pointer-conv-underlying-identity` (`src/typechecker/expressions.js:_pointerConversionOk` compares base type names). Repro: `type B interface{}; var p *B; _ = (*any)(p)` → got `cannot convert *B to *any`, want accepted. (PR #236, checker-go-rules Phase 3, Out of Scope) → unrouted
- **Interface receivers:** a method declared on an interface type is accepted. Root: `method-receiver-interface-check` (`src/typechecker/index.js:collectFunc`/`_attachMethod`). Repro: `type B interface{}; func (b B) Foo() int { return 1 }` → got accepted, want `invalid receiver type B (pointer or interface type)`. (PR #236, checker-go-rules Phase 3, Out of Scope) → unrouted
- **Tagless switch:** `switch { case v: }` with `v any` holding a bool is rejected. Root: `tagless-switch-interface-case` (`src/typechecker/statements.js:_checkTaglessCase` requires `isBool`). Repro: `var v any = true; switch { case v: }` → got `invalid case v in switch`, want accepted (Go: mismatched types any and bool is actually reported — verify before fixing). (PR #236, checker-go-rules Phase 3, Out of Scope) → unrouted
- **wasm type switch:** a case on a defined empty interface does not match on wasm. Root: `wasm-typeswitch-empty-iface` (wasm type-switch matching against defined empty interface). Repro: `type B interface{}; var x any = B(1); switch v := x.(type) { case B: fmt.Println(v) }` → got `` on wasm, want `1`. (PR #236, checker-go-rules Phase 3, Out of Scope) → unrouted
- **Condition messages:** `if v` / `for v` on a defined empty interface report `If condition must be bool` rather than Go's `non-boolean condition`. - **Builtin arity:** builtins do not validate argument counts. Root: `builtin-arg-count` (`src/typechecker/expressions.js:BUILTIN_CHECK` never checks `expr.args.length`). (PR #237, checker-go-rules Phase 4, Out of Scope) → unrouted
- **min/max unification:** `min`/`max` arguments are not unified to one type. Root: `minmax-type-unification` (`expressions.js:_checkMinMax`/`minMaxType` pick the first typed operand and skip `convertUntyped`). Repro: `_ = min(1, "a")` → got compiled on both / ICE on wasm, want `mismatched types untyped int and untyped string`. (PR #237, checker-go-rules Phase 4, Out of Scope) → unrouted

- **Builtins on type parameters:** builtins return early for type parameters without checking the constraint.
